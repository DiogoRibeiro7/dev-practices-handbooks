\section{Usage Notes}

\subsection{Notation Conventions}

Throughout this book, we follow these conventions:

\begin{itemize}
    \item \textbf{Random variables} are denoted by uppercase letters ($X, Y, Z$)
    \item \textbf{Realizations/values} are denoted by lowercase letters ($x, y, z$)
    \item \textbf{Parameters} are denoted by Greek letters ($\theta, \mu, \sigma$)
    \item \textbf{Estimators} are denoted with hats ($\hat{\theta}, \hat{\mu}, \hat{p}$)
    \item \textbf{Vectors} are denoted by bold lowercase letters ($\mathbf{x}, \mathbf{y}$)
    \item \textbf{Matrices} are denoted by bold uppercase letters ($\mathbf{X}, \mathbf{Y}$)
    \item \textbf{Sets} are denoted by calligraphic letters ($\mathcal{D}, \mathcal{N}$)
    \item \textbf{Subscript 0} typically denotes control group
    \item \textbf{Subscript 1} typically denotes treatment group
    \item \textbf{Subscript $i$} indexes individuals or observations
    \item \textbf{Subscript $k$} indexes groups, variants, or arms
\end{itemize}

\subsection{Distribution Notation}

When we write $X \sim \mathcal{D}(\theta)$, we mean "$X$ is distributed according to distribution $\mathcal{D}$ with parameter(s) $\theta$."

Common examples:
\begin{itemize}
    \item $X \sim \mathcal{N}(0, 1)$: $X$ follows a standard normal distribution
    \item $Y \sim \text{Binomial}(n, p)$: $Y$ follows a binomial distribution
    \item $Z \sim \text{Beta}(\alpha, \beta)$: $Z$ follows a beta distribution
\end{itemize}

\subsection{Asymptotic Notation}

\begin{itemize}
    \item $\overset{p}{\to}$: Convergence in probability
    \item $\overset{d}{\to}$: Convergence in distribution
    \item $\overset{a.s.}{\to}$: Almost sure convergence
    \item $O(n)$: Big-O notation (order of magnitude)
    \item $o(n)$: Little-o notation (grows slower than)
\end{itemize}

\subsection{Context-Dependent Notation}

Some symbols have different meanings in different contexts:

\begin{itemize}
    \item $p$ can denote: probability, proportion, p-value, or number of parameters (context-dependent)
    \item $n$ typically denotes sample size but may refer to number of trials in binomial context
    \item $\alpha$ denotes significance level in hypothesis testing, but shape parameter in Beta/Gamma distributions
    \item $\beta$ denotes Type II error rate in hypothesis testing, but shape parameter in Beta distribution or regression coefficient in regression context
\end{itemize}

Always refer to the surrounding text for clarification when ambiguity exists.

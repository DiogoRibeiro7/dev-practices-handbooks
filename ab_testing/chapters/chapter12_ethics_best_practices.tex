\section{Ethical Foundations}

A/B testing involves human subjects and carries ethical responsibilities.

\subsection{Core Ethical Principles}

\begin{enumerate}
    \item \textbf{Beneficence:} Maximize benefits, minimize harms

    \item \textbf{Non-maleficence:} Do no harm

    \item \textbf{Autonomy:} Respect individual agency

    \item \textbf{Justice:} Ensure fair distribution of benefits and burdens

    \item \textbf{Transparency:} Be open about practices
\end{enumerate}

\subsection{The Belmont Report}

While focused on medical research, the Belmont Report's principles apply to digital experimentation:

\begin{itemize}
    \item \textbf{Respect for persons:} Treat individuals as autonomous agents

    \item \textbf{Beneficence:} Maximize possible benefits and minimize possible harms

    \item \textbf{Justice:} Fair distribution of research benefits and burdens
\end{itemize}

\section{Informed Consent}

\subsection{Consent in Digital Experiments}

Unlike medical trials, digital A/B tests typically operate under:

\textbf{General consent:} Users agree to terms of service that may include experimentation

\textbf{Challenges:}
\begin{itemize}
    \item Users rarely read terms of service
    \item Consent may not be truly informed
    \item Ongoing vs. one-time consent
    \item Right to opt out
\end{itemize}

\subsection{When Explicit Consent is Required}

\begin{itemize}
    \item Testing potentially harmful interventions
    \item Collecting sensitive personal data beyond normal use
    \item Significantly changing core functionality
    \item Research published academically
    \item Regulated industries (healthcare, finance, education)
\end{itemize}

\subsection{Balancing Innovation and Consent}

\begin{example}[Acceptable Implicit Consent]
Testing button colors, layout variations, recommendation algorithms—changes within normal product optimization scope.
\end{example}

\begin{example}[Requiring Explicit Consent]
Testing emotional manipulation, significantly degraded experiences, collection of biometric data.
\end{example}

\section{Ethical Guardrails}

\subsection{Minimal Risk Standard}

Experiments should pose no more than minimal risk—risks not greater than encountered in daily life or routine tests.

\textbf{Risk assessment questions:}
\begin{enumerate}
    \item Could this experiment cause physical, psychological, or economic harm?
    \item Are vulnerable populations disproportionately affected?
    \item Is there potential for manipulation or deception?
    \item Could this damage user trust or brand reputation?
    \item Are there privacy or data security concerns?
\end{enumerate}

\subsection{Experimentation Review Board}

Large organizations should establish review processes:

\textbf{Composition:}
\begin{itemize}
    \item Product leaders
    \item Legal/compliance representatives
    \item Ethics officer or designated ethicist
    \item Data scientists
    \item Privacy/security experts
\end{itemize}

\textbf{Responsibilities:}
\begin{itemize}
    \item Review high-risk experiments
    \item Establish ethical guidelines
    \item Provide guidance on edge cases
    \item Monitor incidents and update policies
\end{itemize}

class ExperimentEthicsChecker:
    """Automated ethics and safety checks."""

    def __init__(self):
        self.high_risk_keywords = [
            'children', 'minors', 'emotion', 'manipulation',
            'addiction', 'health', 'safety', 'security'
        ]
        self.sensitive_metrics = [
            'mental_health', 'addiction_score', 'emotional_state'
        ]

    def review_experiment(self, experiment_config):
        """
        Automated ethics review of experiment configuration.

        Returns:
        --------
        dict : Review results and recommendations
        """
        flags = []

        # Check for high-risk keywords in description
        description = experiment_config.get('description', '').lower()
        for keyword in self.high_risk_keywords:
            if keyword in description:
                flags.append({
                    'severity': 'high',
                    'type': 'high_risk_keyword',
                    'message': f"High-risk keyword detected: '{keyword}'",
                    'action': 'Requires human review'
                })

        # Check for sensitive metrics
        metrics = experiment_config.get('metrics', {})
        all_metrics = (metrics.get('primary', []) +
                      metrics.get('secondary', []))

        for metric in all_metrics:
            if metric in self.sensitive_metrics:
                flags.append({
                    'severity': 'high',
                    'type': 'sensitive_metric',
                    'message': f"Sensitive metric: '{metric}'",
                    'action': 'Requires ethics board approval'
                })

        # Check for degraded experiences
        variants = experiment_config.get('variants', [])
        for variant in variants:
            if variant.get('intentionally_degraded', False):
                flags.append({
                    'severity': 'medium',
                    'type': 'degraded_experience',
                    'message': f"Variant {variant['name']} intentionally degraded",
                    'action': 'Document justification'
                })

        # Check target population
        targeting = experiment_config.get('targeting', {})
        if 'age_max' in targeting and targeting['age_max'] < 18:
            flags.append({
                'severity': 'critical',
                'type': 'minors_targeted',
                'message': 'Experiment targets minors',
                'action': 'Ethics board approval and parental consent required'
            })

        return {
            'approved': len([f for f in flags if f['severity'] in
                           ['high', 'critical']]) == 0,
            'flags': flags,
            'recommendation': self._get_recommendation(flags)
        }

    def _get_recommendation(self, flags):
        """Generate recommendation based on flags."""
        if not flags:
            return "No ethical concerns detected. Approved for launch."

        critical = [f for f in flags if f['severity'] == 'critical']
        high = [f for f in flags if f['severity'] == 'high']

        if critical:
            return "BLOCKED: Critical ethical issues. Ethics board review required."
        elif high:
            return "CAUTION: High-risk experiment. Manager approval required."
        else:
            return "PROCEED WITH CAUTION: Document ethical considerations."

# Example usage
experiment = {
    'description': 'Testing notification frequency to increase engagement',
    'metrics': {
        'primary': 'daily_active_users',
        'secondary': ['session_duration', 'notification_clicks']
    },
    'variants': [
        {'name': 'control', 'notification_freq': 1},
        {'name': 'treatment', 'notification_freq': 10}
    ]
}

result = checker.review_experiment(experiment)

print(f"Approved: {result['approved']}")
print(f"Recommendation: {result['recommendation']}")
for flag in result['flags']:
    print(f"  - {flag['message']}")

\section{Privacy and Data Protection}

\subsection{Data Minimization}

Collect only data necessary for the experiment:

\begin{itemize}
    \item Define metrics clearly and collect only those
    \item Aggregate early when possible
    \item Delete raw data after analysis
    \item Anonymize or pseudonymize user identifiers
\end{itemize}

\subsection{Regulatory Compliance}

\textbf{GDPR (General Data Protection Regulation):}
\begin{itemize}
    \item Right to access: Users can request their data
    \item Right to erasure: "Right to be forgotten"
    \item Data protection by design
    \item Lawful basis for processing
\end{itemize}

\textbf{CCPA (California Consumer Privacy Act):}
\begin{itemize}
    \item Right to know what data is collected
    \item Right to delete personal information
    \item Right to opt out of sale
    \item Non-discrimination for exercising rights
\end{itemize}

\subsection{Internal Data Governance}

\begin{enumerate}
    \item \textbf{Access controls:} Limit who can view individual-level data

    \item \textbf{Audit trails:} Log data access and analysis

    \item \textbf{Retention policies:} Delete data after specified period

    \item \textbf{Anonymization:} Remove personally identifiable information

    \item \textbf{Differential privacy:} Add noise to protect individual privacy
\end{enumerate}

\section{Regulatory Compliance}

Operating in regulated environments requires understanding and complying with industry-specific requirements for experimentation.

\subsection{GDPR and Data Protection Laws}

\textbf{Key GDPR requirements for experiments:}

\begin{enumerate}
    \item \textbf{Lawful basis:} Identify legal basis for processing
    \begin{itemize}
        \item Consent: Explicit agreement to participate
        \item Legitimate interest: Balancing test for product improvement
        \item Contract: Necessary for service delivery
    \end{itemize}

    \item \textbf{Data minimization:} Collect only necessary data

    \item \textbf{Purpose limitation:} Use data only for stated purpose

    \item \textbf{Storage limitation:} Delete data when no longer needed

    \item \textbf{Data subject rights:}
    \begin{itemize}
        \item Right to access experimental data
        \item Right to erasure ("right to be forgotten")
        \item Right to object to processing
        \item Right to data portability
    \end{itemize}

    \item \textbf{Data Protection Impact Assessment (DPIA):} Required for high-risk processing
\end{enumerate}

\begin{lstlisting}
from enum import Enum
from dataclasses import dataclass
from typing import List, Optional

class LegalBasis(Enum):
    """GDPR legal basis for processing."""
    CONSENT = "consent"
    CONTRACT = "contract"
    LEGAL_OBLIGATION = "legal_obligation"
    VITAL_INTERESTS = "vital_interests"
    PUBLIC_TASK = "public_task"
    LEGITIMATE_INTEREST = "legitimate_interest"

class DataCategory(Enum):
    """Categories of personal data."""
    STANDARD = "standard"  # Name, email, etc.
    SPECIAL = "special"  # Race, health, religion, etc.
    CRIMINAL = "criminal"  # Criminal convictions

@dataclass
class GDPRComplianceAssessment:
    """Assess GDPR compliance for A/B test."""

    experiment_name: str
    legal_basis: LegalBasis
    data_collected: List[str]
    data_categories: List[DataCategory]
    retention_period_days: int
    third_party_sharing: bool
    automated_decision_making: bool
    children_targeted: bool

    def assess_dpia_required(self) -> bool:
        """
        Determine if Data Protection Impact Assessment is required.

        DPIA required if:
        - Processing special category data at scale
        - Systematic monitoring of public areas
        - Automated decision-making with legal/significant effects
        - Processing children's data at scale
        """
        high_risk_factors = []

        # Special category data
        if DataCategory.SPECIAL in self.data_categories:
            high_risk_factors.append("Processing special category data")

        # Automated decisions with significant impact
        if self.automated_decision_making:
            high_risk_factors.append("Automated decision-making")

        # Children's data
        if self.children_targeted:
            high_risk_factors.append("Targeting children")

        # Large scale processing
        if self.retention_period_days > 365:
            high_risk_factors.append("Long-term data retention")

        return len(high_risk_factors) >= 2

    def check_compliance(self) -> Dict:
        """Comprehensive GDPR compliance check."""
        issues = []
        warnings = []

        # Check legal basis is appropriate
        if (DataCategory.SPECIAL in self.data_categories and
            self.legal_basis not in [LegalBasis.CONSENT,
                                    LegalBasis.LEGAL_OBLIGATION]):
            issues.append({
                'severity': 'critical',
                'issue': 'Invalid legal basis for special category data',
                'remedy': 'Obtain explicit consent or identify legal obligation'
            })

        # Check retention period
        if self.retention_period_days > 730:  # 2 years
            warnings.append({
                'severity': 'medium',
                'issue': f'Long retention period: {self.retention_period_days} days',
                'remedy': 'Document necessity for extended retention'
            })

        # Check children's data
        if self.children_targeted and self.legal_basis != LegalBasis.CONSENT:
            issues.append({
                'severity': 'critical',
                'issue': 'Processing children data without parental consent',
                'remedy': 'Obtain verifiable parental consent'
            })

        # Check third-party sharing
        if self.third_party_sharing:
            warnings.append({
                'severity': 'high',
                'issue': 'Third-party data sharing detected',
                'remedy': 'Ensure data processing agreements in place'
            })

        # DPIA assessment
        dpia_required = self.assess_dpia_required()
        if dpia_required:
            warnings.append({
                'severity': 'high',
                'issue': 'Data Protection Impact Assessment required',
                'remedy': 'Conduct DPIA before launching experiment'
            })

        return {
            'compliant': len(issues) == 0,
            'dpia_required': dpia_required,
            'critical_issues': issues,
            'warnings': warnings,
            'recommendation': self._get_recommendation(issues, warnings)
        }

    def _get_recommendation(self, issues: List, warnings: List) -> str:
        """Generate compliance recommendation."""
        if issues:
            return "BLOCKED: Critical GDPR compliance issues. Legal review required."
        elif warnings:
            return f"PROCEED WITH CAUTION: {len(warnings)} compliance warnings. Document mitigations."
        else:
            return "COMPLIANT: No GDPR issues detected."

# Example usage
assessment = GDPRComplianceAssessment(
    experiment_name="Personalized Health Recommendations Test",
    legal_basis=LegalBasis.LEGITIMATE_INTEREST,
    data_collected=["user_id", "health_conditions", "medications"],
    data_categories=[DataCategory.SPECIAL],  # Health data
    retention_period_days=90,
    third_party_sharing=False,
    automated_decision_making=True,
    children_targeted=False
)

result = assessment.check_compliance()
print(f"Compliant: {result['compliant']}")
print(f"DPIA Required: {result['dpia_required']}")
print(f"Recommendation: {result['recommendation']}")
\end{lstlisting}

\subsection{HIPAA (Healthcare)}

For experiments involving Protected Health Information (PHI):

\textbf{HIPAA requirements:}
\begin{itemize}
    \item \textbf{Authorization:} Obtain patient authorization for research use
    \item \textbf{De-identification:} Remove 18 identifiers or use expert determination
    \item \textbf{Limited data sets:} Remove direct identifiers, use data use agreement
    \item \textbf{Business Associate Agreements:} Required for third-party processors
    \item \textbf{Security Rule:} Technical safeguards for ePHI
\end{itemize}

\textbf{Safe harbor de-identification (remove all):}
\begin{multicols}{2}
\begin{enumerate}
    \item Names
    \item Geographic subdivisions smaller than state
    \item Dates (except year)
    \item Phone numbers
    \item Fax numbers
    \item Email addresses
    \item Social Security numbers
    \item Medical record numbers
    \item Health plan numbers
    \item Account numbers
    \item Certificate/license numbers
    \item Vehicle identifiers
    \item Device identifiers/serial numbers
    \item URLs
    \item IP addresses
    \item Biometric identifiers
    \item Full-face photos
    \item Any unique identifying number
\end{enumerate}
\end{multicols}

\subsection{COPPA (Children's Privacy)}

Testing products used by children under 13 in the US:

\textbf{COPPA requirements:}
\begin{itemize}
    \item \textbf{Parental consent:} Obtain verifiable consent before collecting data
    \item \textbf{Clear privacy notice:} Disclose data collection practices
    \item \textbf{Data minimization:} Collect only necessary information
    \item \textbf{Parental access:} Allow parents to review and delete data
    \item \textbf{Security:} Reasonable safeguards for children's data
\end{itemize}

\textbf{Age gate implementation:}
\begin{itemize}
    \item Neutral age screening (don't encourage lying)
    \item Age verification mechanisms
    \item Separate consent flows for under-13 users
    \item Parental email verification
\end{itemize}

\subsection{Financial Services Regulations}

Experiments in banking, lending, or financial services:

\textbf{Key regulations:}
\begin{itemize}
    \item \textbf{Fair Lending Laws:} Ensure non-discrimination in credit decisions
    \item \textbf{FCRA (Fair Credit Reporting Act):} Accuracy in credit decisions
    \item \textbf{GLBA (Gramm-Leach-Bliley Act):} Privacy of financial information
    \item \textbf{Dodd-Frank Act:} Consumer protection in financial products
\end{itemize}

\textbf{Testing lending algorithms:}
\begin{enumerate}
    \item \textbf{Disparate impact analysis:} Test for discrimination across protected groups
    \item \textbf{Adverse action notices:} Inform consumers of credit denials
    \item \textbf{Model governance:} Document and validate models
    \item \textbf{Fair lending compliance:} Ensure equal treatment
\end{enumerate}

import pandas as pd
import numpy as np
from scipy import stats

class FairLendingAnalyzer:
    """Analyze experiments for fair lending compliance."""

    def __init__(self, data: pd.DataFrame):
        self.data = data
        self.protected_classes = ['race', 'gender', 'age_group', 'national_origin']

    def disparate_impact_test(self, outcome_col: str = 'approved',
                              threshold: float = 0.80) -> Dict:
        """
        Test for disparate impact using the 80% rule.

        The 80% rule: Selection rate for protected group should be
        at least 80% of selection rate for most favored group.
        """
        results = {}

        for protected_class in self.protected_classes:
            if protected_class not in self.data.columns:
                continue

            # Calculate approval rates by group
            approval_rates = (self.data.groupby(protected_class)[outcome_col]
                            .mean()
                            .sort_values(ascending=False))

            reference_rate = approval_rates.iloc[0]  # Highest rate

            # Calculate ratios
            ratios = approval_rates / reference_rate

            # Identify disparate impact
            failing_groups = ratios[ratios < threshold]

            results[protected_class] = {
                'approval_rates': approval_rates.to_dict(),
                'reference_group': approval_rates.index[0],
                'reference_rate': reference_rate,
                'ratios': ratios.to_dict(),
                'disparate_impact_detected': len(failing_groups) > 0,
                'failing_groups': failing_groups.to_dict()
            }

        return results

    def statistical_significance_test(self, variant_col: str,
                                     outcome_col: str = 'approved') -> Dict:
        """Test if approval rates differ significantly by variant and protected class."""
        results = {}

        for protected_class in self.protected_classes:
            if protected_class not in self.data.columns:
                continue

            # Create contingency table
            contingency = pd.crosstab(
                [self.data[variant_col], self.data[protected_class]],
                self.data[outcome_col]
            )

            # Chi-square test
            chi2, p_value, dof, expected = stats.chi2_contingency(contingency)

            results[protected_class] = {
                'chi2_statistic': chi2,
                'p_value': p_value,
                'significant': p_value < 0.05,
                'contingency_table': contingency.to_dict()
            }

        return results

    def generate_compliance_report(self, variant_col: str = 'variant') -> str:
        """Generate fair lending compliance report."""
        disparate_impact = self.disparate_impact_test()
        significance = self.statistical_significance_test(variant_col)

        report = ["Fair Lending Compliance Analysis", "="*50, ""]

        # Disparate impact results
        report.append("Disparate Impact Test (80% Rule):")
        report.append("-" * 40)

        for protected_class, results in disparate_impact.items():
            report.append(f"\n{protected_class.upper()}:")
            report.append(f"  Reference group: {results['reference_group']} "
                        f"({results['reference_rate']:.1%})")

            if results['disparate_impact_detected']:
                report.append("  WARNING: Disparate impact detected!")
                for group, ratio in results['failing_groups'].items():
                    rate = results['approval_rates'][group]
                    report.append(f"    {group}: {rate:.1%} ({ratio:.1%} of reference)")
            else:
                report.append("  PASS: No disparate impact detected")

        return "\n".join(report)

\section{Experimental Integrity}

Maintaining scientific rigor and avoiding statistical malpractice is essential for trustworthy experimentation.

\subsection{Pre-registration and Documentation}

\textbf{Why pre-registration matters:}
\begin{itemize}
    \item Prevents p-hacking and HARKing (Hypothesizing After Results are Known)
    \item Creates accountability for experimental design
    \item Enables distinction between confirmatory and exploratory analysis
    \item Builds institutional knowledge
\end{itemize}

\textbf{What to pre-register:}
\begin{enumerate}
    \item Research question and hypothesis
    \item Primary and secondary metrics
    \item Planned sample size and duration
    \item Statistical analysis plan
    \item Subgroup analyses (if planned)
    \item Decision criteria for shipping
\end{enumerate}

\lstset{language=Python, caption=Pre-registration Framework}
\begin{lstlisting}
from dataclasses import dataclass, field
from typing import List, Dict, Optional
from datetime import datetime
import json
import hashlib

@dataclass
class ExperimentPreRegistration:
    """
    Pre-registration document for A/B test experiments.
    Creates immutable record of experimental design before execution.
    """
    # Basic information
    experiment_id: str
    experiment_name: str
    owner: str
    registration_date: datetime = field(default_factory=datetime.now)

    # Research design
    hypothesis: str
    rationale: str

    # Metrics
    primary_metric: str
    primary_metric_definition: str
    secondary_metrics: List[str] = field(default_factory=list)
    guardrail_metrics: List[str] = field(default_factory=list)

    # Statistical design
    minimum_detectable_effect: float
    significance_level: float = 0.05
    statistical_power: float = 0.80
    planned_sample_size: int
    planned_duration_days: int

    # Analysis plan
    statistical_test: str  # e.g., "two-sample t-test", "mann-whitney"
    multiple_testing_correction: str  # e.g., "bonferroni", "benjamini-hochberg"
    planned_subgroups: List[str] = field(default_factory=list)

    # Decision criteria
    success_criteria: str
    launch_threshold: str  # e.g., "p < 0.05 and lift > 2%"

    # Additional fields
    exclusion_criteria: Optional[str] = None
    randomization_unit: str = "user_id"
    traffic_allocation: Dict[str, float] = field(default_factory=dict)

    def generate_hash(self) -> str:
        """Generate cryptographic hash of pre-registration for tamper detection."""
        # Serialize registration to JSON
        reg_dict = {
            'experiment_id': self.experiment_id,
            'hypothesis': self.hypothesis,
            'primary_metric': self.primary_metric,
            'significance_level': self.significance_level,
            'planned_sample_size': self.planned_sample_size,
            'statistical_test': self.statistical_test,
            'success_criteria': self.success_criteria
        }

        # Create hash
        reg_json = json.dumps(reg_dict, sort_keys=True)
        return hashlib.sha256(reg_json.encode()).hexdigest()

    def to_dict(self) -> Dict:
        """Convert to dictionary for storage."""
        return {
            'experiment_id': self.experiment_id,
            'experiment_name': self.experiment_name,
            'owner': self.owner,
            'registration_date': self.registration_date.isoformat(),
            'hypothesis': self.hypothesis,
            'rationale': self.rationale,
            'primary_metric': self.primary_metric,

\subsection{Avoiding P-Hacking and Data Dredging}

\textbf{Common p-hacking practices to avoid:}

\begin{enumerate}
    \item \textbf{Peeking:} Looking at results before planned sample size and stopping early if significant

    \item \textbf{Metric switching:} Declaring different metric as primary post-hoc

    \item \textbf{Subgroup fishing:} Testing many subgroups without correction

    \item \textbf{Outlier removal:} Removing data points to achieve significance

    \item \textbf{Optional stopping:} Repeatedly checking for significance

    \item \textbf{Flexible analysis:} Trying multiple statistical tests until one is significant
\end{enumerate}

\textbf{Safeguards against p-hacking:}

\lstset{language=Python, caption=P-Hacking Detection and Prevention}
\begin{lstlisting}
class ExperimentIntegrityMonitor:
    """Monitor and prevent statistical malpractice in experiments."""

    def __init__(self, pre_registration: ExperimentPreRegistration):
        self.pre_reg = pre_registration
        self.analysis_log = []

    def log_analysis(self, analysis_type: str, metric: str,
                    p_value: float, notes: str):
        """Log every statistical analysis performed."""
        self.analysis_log.append({
            'timestamp': datetime.now(),
            'analysis_type': analysis_type,
            'metric': metric,
            'p_value': p_value,
            'notes': notes
        })

    def check_analysis_integrity(self) -> Dict:
        """
        Check for signs of p-hacking or fishing.

        Returns:
        --------
        dict : Integrity assessment and warnings
        """
        warnings = []

        # Check for multiple looks at data
        primary_analyses = [a for a in self.analysis_log
                          if a['metric'] == self.pre_reg.primary_metric]
        if len(primary_analyses) > 1:
            warnings.append({
                'severity': 'high',
                'issue': 'multiple_testing',
                'message': f"Primary metric analyzed {len(primary_analyses)} times. "
                          f"May indicate peeking or optional stopping."
            })

        # Check for fishing across metrics
        unique_metrics = set(a['metric'] for a in self.analysis_log)
        expected_metrics = {self.pre_reg.primary_metric} | set(
            self.pre_reg.secondary_metrics)

        unexpected_metrics = unique_metrics - expected_metrics
        if unexpected_metrics:
            warnings.append({
                'severity': 'high',
                'issue': 'metric_fishing',
                'message': f"Metrics not in pre-registration analyzed: "
                          f"{unexpected_metrics}. May indicate fishing."
            })

        # Check for subgroup fishing
        subgroup_analyses = [a for a in self.analysis_log
                           if 'subgroup' in a.get('notes', '')]
        if len(subgroup_analyses) > len(self.pre_reg.planned_subgroups):
            warnings.append({
                'severity': 'medium',
                'issue': 'subgroup_fishing',
                'message': f"More subgroup analyses ({len(subgroup_analyses)}) "
                          f"than pre-registered ({len(self.pre_reg.planned_subgroups)})"
            })

        # Check for excessive analyses
        if len(self.analysis_log) > 20:
            warnings.append({
                'severity': 'medium',
                'issue': 'excessive_analysis',
                'message': f"{len(self.analysis_log)} analyses logged. "
                          f"Review for fishing behavior."
            })

        return {
            'integrity_score': max(0, 100 - len(warnings) * 20),
            'warnings': warnings,
            'total_analyses': len(self.analysis_log),
            'analysis_log': self.analysis_log
        }

    def enforce_multiple_testing_correction(self, p_values: List[float]) -> Dict:
        """Apply multiple testing correction as specified in pre-registration."""
        from scipy import stats

        method = self.pre_reg.multiple_testing_correction.lower()

        if method == 'bonferroni':
            alpha_corrected = self.pre_reg.significance_level / len(p_values)
            reject = [p < alpha_corrected for p in p_values]

        elif method == 'benjamini-hochberg' or method == 'fdr':
            # Benjamini-Hochberg FDR control
            reject, p_adjusted, _, _ = stats.multipletests(
                p_values, alpha=self.pre_reg.significance_level,
                method='fdr_bh'
            )
            reject = list(reject)

        elif method == 'holm':
            reject, p_adjusted, _, _ = stats.multipletests(
                p_values, alpha=self.pre_reg.significance_level,
                method='holm'
            )
            reject = list(reject)

        else:
            raise ValueError(f"Unknown correction method: {method}")

        return {
            'method': method,
            'original_alpha': self.pre_reg.significance_level,
            'n_tests': len(p_values),
            'p_values_original': p_values,
            'reject_null': reject,
            'significant_count': sum(reject)
        }

class ExperimentGovernance:
    """Governance framework for experiment approval."""

    experiment_id: str
    name: str
    owner: str
    description: str
    risk_tier: RiskTier
    affected_users: int
    revenue_impact_estimated: Optional[float] = None
    user_experience_impact: str = "neutral"  # "positive", "neutral", "negative"

    approved: bool = False
    approval_date: Optional[datetime] = None

    def classify_risk_tier(self) -> RiskTier:
        """
        Automatically classify experiment risk tier based on characteristics.
        """
        risk_score = 0

        # User impact
        if self.affected_users > 1_000_000:
            risk_score += 2
        elif self.affected_users > 100_000:
            risk_score += 1

        # Revenue impact
        if self.revenue_impact_estimated and abs(self.revenue_impact_estimated) > 1_000_000:
            risk_score += 2
        elif self.revenue_impact_estimated and abs(self.revenue_impact_estimated) > 100_000:
            risk_score += 1

        # User experience
        if self.user_experience_impact == "negative":
            risk_score += 2

        # Map score to tier
        if risk_score == 0:
            return RiskTier.MINIMAL
        elif risk_score <= 2:
            return RiskTier.LOW
        elif risk_score <= 4:
            return RiskTier.MEDIUM
        elif risk_score <= 6:
            return RiskTier.HIGH
        else:
            return RiskTier.CRITICAL

    def get_required_approvers(self) -> List[str]:
        """Get list of required approvers based on risk tier."""
        approver_map = {
            RiskTier.MINIMAL: [],
            RiskTier.LOW: ["manager"],
            RiskTier.MEDIUM: ["manager", "director", "data_science_lead"],
            RiskTier.HIGH: ["director", "vp", "ethics_board"],
            RiskTier.CRITICAL: ["vp", "legal", "ethics_board", "executive"]
        }

            'owner': self.owner,

    \item \textbf{Implementation review:}
    \begin{itemize}

from dataclasses import dataclass
from typing import List, Dict, Optional
from datetime import datetime

@dataclass
class ReviewChecklist:
    """Structured peer review checklist."""

    experiment_id: str
    review_stage: str  # 'design', 'implementation', 'analysis'
    reviewer: str
    review_date: datetime

    # Checklist items (True = pass, False = fail, None = not applicable)
    checks: Dict[str, Optional[bool]]
    comments: Dict[str, str]

    def is_approved(self) -> bool:
        """Check if review passes (no False values)."""
        return all(v is not False for v in self.checks.values())

    def get_blocking_issues(self) -> List[str]:
        """Get list of failed checks."""
        return [item for item, passed in self.checks.items() if passed is False]

    def generate_review_report(self) -> str:
        """Generate review summary."""
        status = "APPROVED" if self.is_approved() else "NEEDS REVISION"
        blocking = self.get_blocking_issues()

        report = [
            f"Peer Review Report: {self.experiment_id}",
            f"Stage: {self.review_stage}",
            f"Reviewer: {self.reviewer}",
            f"Date: {self.review_date.strftime('%Y-%m-%d')}",
            f"Status: {status}",
            ""
        ]

        if blocking:
            report.append("BLOCKING ISSUES:")
            for issue in blocking:
                report.append(f"  ✗ {issue}")
                if issue in self.comments:
                    report.append(f"    Comment: {self.comments[issue]}")
            report.append("")

        # Passed items
        passed = [item for item, v in self.checks.items() if v is True]
        if passed:
            report.append("PASSED CHECKS:")
            for item in passed:
                report.append(f"  ✓ {item}")

        return "\n".join(report)

\subsection{Statistical Consulting}

\begin{itemize}
    \item Novel experimental designs (e.g., switchback tests, multi-armed bandits)

\textbf{Statistical consulting workflow:}

\begin{enumerate}
    \item \textbf{Intake:} Team submits consultation request with context
    \item \textbf{Review:} Statistician reviews design/analysis
    \item \textbf{Consultation:} 30-60 minute discussion
    \item \textbf{Recommendations:} Written guidance provided
    \item \textbf{Follow-up:} Optional review of final analysis
\end{enumerate}

class ExperimentValidator:
    """Comprehensive automated validation for experiments."""

    def __init__(self, experiment_data: pd.DataFrame,
                 experiment_config: Dict):
        self.data = experiment_data
        self.config = experiment_config
        self.validation_results = {}

    def validate_all(self) -> Dict:
        """Run all validation checks."""
        validations = [
            ('sample_ratio_mismatch', self.check_sample_ratio_mismatch),
            ('assignment_consistency', self.check_assignment_consistency),
            ('data_completeness', self.check_data_completeness),
            ('metric_sanity', self.check_metric_sanity),
            ('temporal_stability', self.check_temporal_stability),
            ('outliers', self.check_outlier_prevalence),
            ('guardrails', self.check_guardrail_metrics)
        ]

        results = {}
        all_passed = True

        for name, check_func in validations:
            try:
                result = check_func()
                results[name] = result
                if not result.get('passed', False):
                    all_passed = False
            except Exception as e:
                results[name] = {'passed': False, 'error': str(e)}
                all_passed = False

        return {
            'all_passed': all_passed,
            'checks': results,
            'summary': self._generate_summary(results)
        }

    def check_sample_ratio_mismatch(self) -> Dict:
        """Check if variant sizes match expected allocation."""
        from scipy import stats

        variant_counts = self.data['variant'].value_counts()
        total = len(self.data)

        expected_allocation = self.config.get('traffic_allocation', {})

        # Chi-square goodness of fit
        expected_counts = [total * expected_allocation.get(v, 1/len(variant_counts))
                          for v in variant_counts.index]

        chi2, p_value = stats.chisquare(variant_counts.values, expected_counts)

        passed = p_value >= 0.01  # Use stricter threshold for SRM

        return {
            'passed': passed,
            'p_value': p_value,
            'chi2_statistic': chi2,
            'observed_counts': variant_counts.to_dict(),
            'expected_counts': dict(zip(variant_counts.index, expected_counts)),
            'severity': 'critical' if not passed else 'none',
            'message': 'Sample Ratio Mismatch detected!' if not passed else 'Sample ratios OK'
        }

    def check_guardrail_metrics(self) -> Dict:
        """Ensure guardrail metrics haven't degraded."""
        guardrails = self.config.get('guardrail_metrics', [])
        violations = []

        for metric in guardrails:
            if metric not in self.data.columns:
                continue

            control = self.data[self.data['variant'] == 'control'][metric]
            treatment = self.data[self.data['variant'] == 'treatment'][metric]

            # Check if treatment is worse than control (with margin)
            degradation_threshold = 0.01  # 1% degradation allowed

            relative_change = (treatment.mean() - control.mean()) / control.mean()

            if relative_change < -degradation_threshold:
                violations.append({
                    'metric': metric,
                    'degradation': relative_change,
                    'control_mean': control.mean(),
                    'treatment_mean': treatment.mean()
                })

        passed = len(violations) == 0

        return {
            'passed': passed,
            'violations': violations,
            'severity': 'high' if not passed else 'none',
            'message': f"{len(violations)} guardrail violations" if not passed else "All guardrails OK"
        }

    def _generate_summary(self, results: Dict) -> str:
        """Generate human-readable summary."""
        critical = [name for name, r in results.items()
                   if r.get('severity') == 'critical']
        high = [name for name, r in results.items()
               if r.get('severity') == 'high']

        if critical:
            return f"BLOCKED: Critical issues - {', '.join(critical)}"
        elif high:
            return f"WARNING: High-priority issues - {', '.join(high)}"
        else:
            return "PASS: All validation checks passed"

\section{Summary}

Ethical and effective experimentation requires:

\begin{itemize}
    \item Commitment to ethical principles and user welfare
    \item Robust governance and review processes
    \item Privacy protection and regulatory compliance
    \item Transparency internally and externally
    \item Strong organizational culture supporting experimentation
    \item Continuous learning and improvement
\end{itemize}

A/B testing is powerful but carries responsibility. Practitioners must balance innovation with ethics, rigor with pragmatism, and data with judgment.

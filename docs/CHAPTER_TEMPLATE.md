# Chapter Template

Use this template when adding or expanding chapters. Keep sections in this order.

1. **Motivation and Learning Objectives**
   - Explain why the topic matters now (incident, risk, release pressure).
   - List at least two concrete learning goals for the reader.

2. **Core Concepts**
   - Cover the foundational pieces of the chapter. Use subsections for each concept or pattern.
   - Preserve existing prose under the appropriate concept; avoid rewriting unless necessary.

3. **Anti-patterns and Common Mistakes**
   - List at least three traps teams fall into.
   - Mark TODOs where specific examples are still pending.

4. **Worked Example**
   - Show runnable code (or pseudo code) that runs in CI (e.g., Python, Bash, YAML).
   - Highlight how the code demonstrates the chapter’s concept.
   - Add `TODO` comments for incomplete snippets.

5. **Checklist**
   - Provide 3–6 actionable bullet points that summarize the key practices.

6. **Exercises**
   - Offer 2–4 prompts that encourage hands-on practice (risk modeling, writing charters, etc.).

7. **Further Reading**
   - Reference at least two sources (books, blog posts, docs) that reinforce the material.

Maintain a consistent voice (active, direct) and format (short paragraphs, `\begin{lstlisting}` for code). Add `TODO` markers for work that still needs content.

\section{Introduction}

ML models in production face unique challenges: data distributions shift, model performance degrades, infrastructure fails, and business requirements change. Without comprehensive monitoring, teams discover issues only after significant business impact. Production ML monitoring requires tracking not just traditional software metrics (latency, throughput, errors), but also ML-specific concerns like data drift, prediction quality, and model staleness.

Effective ML monitoring provides:
\begin{itemize}
    \item \textbf{Early warning:} Detect degradation before business impact
    \item \textbf{Root cause analysis:} Understand why models fail
    \item \textbf{Continuous validation:} Ensure ongoing model quality
    \item \textbf{Compliance:} Audit trail for regulatory requirements
    \item \textbf{Optimization insights:} Data for model improvement
\end{itemize}

This chapter covers production-grade monitoring systems that combine traditional observability with ML-specific metrics.

class Metric:

class MetricsCollector:
    """
    Collect and store ML system metrics

    Provides thread-safe metric collection with buffering
    """

    def __init__(self, buffer_size: int = 10000):
        """
        Initialize metrics collector

        Args:
            buffer_size: Maximum metrics to buffer before flush
        """
        self.metrics_buffer: deque = deque(maxlen=buffer_size)
        self.counters: Dict[str, float] = {}
        self.gauges: Dict[str, float] = {}
        self.histograms: Dict[str, List[float]] = {}
        self.logger = logging.getLogger("MetricsCollector")

    def record_counter(self, name: str, value: float = 1,
                      labels: Dict[str, str] = None):
        """
        Record a counter metric (monotonically increasing)

        Args:
            name: Metric name
            value: Increment amount
            labels: Metric labels
        """
        key = self._make_key(name, labels)
        self.counters[key] = self.counters.get(key, 0) + value

        self._buffer_metric(Metric(
            name=name,
            value=self.counters[key],
            timestamp=datetime.now(),
            labels=labels or {},
            metric_type=MetricType.COUNTER
        ))

    def record_gauge(self, name: str, value: float,
                    labels: Dict[str, str] = None):
        """
        Record a gauge metric (can go up or down)

        Args:
            name: Metric name
            value: Current value
            labels: Metric labels
        """
        key = self._make_key(name, labels)
        self.gauges[key] = value

        self._buffer_metric(Metric(
            name=name,
            value=value,
            timestamp=datetime.now(),
            labels=labels or {},
            metric_type=MetricType.GAUGE
        ))

    def record_histogram(self, name: str, value: float,
                        labels: Dict[str, str] = None):
        """
        Record a histogram metric (distribution of values)

        Args:
            name: Metric name
            value: Observed value
            labels: Metric labels
        """
        key = self._make_key(name, labels)
        if key not in self.histograms:
            self.histograms[key] = []

        self.histograms[key].append(value)

        self._buffer_metric(Metric(
            name=name,
            value=value,
            timestamp=datetime.now(),
            labels=labels or {},
            metric_type=MetricType.HISTOGRAM
        ))

    def get_metrics(self, name: str = None,
                   start_time: datetime = None,
                   end_time: datetime = None) -> List[Metric]:
        """
        Retrieve metrics from buffer

        Args:
            name: Filter by metric name
            start_time: Filter by start time
            end_time: Filter by end time

        Returns:
            Filtered list of metrics
        """
        metrics = list(self.metrics_buffer)

        if name:
            metrics = [m for m in metrics if m.name == name]

        if start_time:
            metrics = [m for m in metrics if m.timestamp >= start_time]

        if end_time:
            metrics = [m for m in metrics if m.timestamp <= end_time]

        return metrics

    def get_histogram_percentiles(self, name: str,
                                  labels: Dict[str, str] = None,
                                  percentiles: List[float] = [50, 95, 99]) -> Dict[float, float]:
        """
        Calculate histogram percentiles

        Args:
            name: Metric name
            labels: Metric labels
            percentiles: Percentiles to calculate

        Returns:
            Dictionary of percentile values
        """
        key = self._make_key(name, labels)
        values = self.histograms.get(key, [])

        if not values:
            return {p: 0.0 for p in percentiles}

        return {
            p: np.percentile(values, p)
            for p in percentiles
        }

    def _make_key(self, name: str, labels: Dict[str, str] = None) -> str:
        """Create unique key for metric"""
        if not labels:
            return name

        label_str = ",".join(f"{k}={v}" for k, v in sorted(labels.items()))
        return f"{name}{{{label_str}}}"

    def _buffer_metric(self, metric: Metric):
        """Add metric to buffer"""
        self.metrics_buffer.append(metric)

    def flush(self) -> List[Metric]:
        """
        Flush all buffered metrics

        Returns:
            All buffered metrics
        """
        metrics = list(self.metrics_buffer)
        self.metrics_buffer.clear()
        return metrics

class MonitoringArchitecture:
    """
    Complete ML monitoring architecture

    Coordinates metrics collection, storage, and alerting
    """

    def __init__(self,
                 metrics_collector: MetricsCollector,
                 storage_backend: Optional[Any] = None):
        """
        Initialize monitoring architecture

        Args:
            metrics_collector: Metrics collector instance
            storage_backend: Backend for metric storage (e.g., Prometheus)
        """
        self.metrics = metrics_collector
        self.storage = storage_backend
        self.alerts: Dict[str, Alert] = {}
        self.logger = logging.getLogger("MonitoringArchitecture")

        # Standard ML metrics
        self._register_standard_metrics()

    def _register_standard_metrics(self):
        """Register standard ML metrics"""
        self.standard_metrics = {
            'prediction_count': MetricType.COUNTER,
            'prediction_latency_ms': MetricType.HISTOGRAM,
            'model_accuracy': MetricType.GAUGE,
            'data_drift_score': MetricType.GAUGE,
            'feature_null_count': MetricType.COUNTER,
            'prediction_confidence': MetricType.HISTOGRAM,
            'error_count': MetricType.COUNTER,
            'cache_hit_rate': MetricType.GAUGE
        }

    def record_prediction(self,
                         model_name: str,
                         model_version: str,
                         features: Dict[str, Any],
                         prediction: Any,
                         confidence: float,
                         latency_ms: float):
        """
        Record a model prediction with all associated metrics

        Args:
            model_name: Name of model
            model_version: Model version
            features: Input features
            prediction: Model prediction
            confidence: Prediction confidence
            latency_ms: Prediction latency
        """
        labels = {
            'model_name': model_name,
            'model_version': model_version
        }

        # Record prediction count
        self.metrics.record_counter(
            'prediction_count',
            value=1,
            labels=labels
        )

        # Record latency
        self.metrics.record_histogram(
            'prediction_latency_ms',
            value=latency_ms,
            labels=labels
        )

        # Record confidence
        self.metrics.record_histogram(
            'prediction_confidence',
            value=confidence,
            labels=labels
        )

        # Check for null features
        null_count = sum(1 for v in features.values() if v is None)
        if null_count > 0:
            self.metrics.record_counter(
                'feature_null_count',
                value=null_count,
                labels=labels
            )

    def record_ground_truth(self,
                           model_name: str,
                           model_version: str,
                           prediction: Any,
                           actual: Any,
                           metric_value: float):
        """
        Record ground truth and calculate accuracy

        Args:
            model_name: Name of model
            model_version: Model version
            prediction: Model prediction
            actual: Actual value
            metric_value: Calculated metric (e.g., accuracy, error)
        """
        labels = {
            'model_name': model_name,
            'model_version': model_version
        }

        # Record metric
        self.metrics.record_gauge(
            'model_accuracy',
            value=metric_value,
            labels=labels
        )

        # Record if prediction was correct
        correct = 1 if prediction == actual else 0
        self.metrics.record_counter(
            'correct_predictions',
            value=correct,
            labels=labels
        )

    def register_alert(self, alert: Alert):
        """
        Register an alert condition

        Args:
            alert: Alert configuration
        """
        self.alerts[alert.alert_id] = alert
        self.logger.info(f"Registered alert: {alert.name}")

    def check_alerts(self) -> List[Dict]:
        """
        Check all registered alerts

        Returns:
            List of triggered alerts
        """
        triggered_alerts = []

        for alert_id, alert in self.alerts.items():
            # Check cooldown
            if alert.last_triggered:
                time_since = datetime.now() - alert.last_triggered
                if time_since.total_seconds() < alert.cooldown_minutes * 60:
                    continue

            # Evaluate condition
            try:
                if alert.condition(self.metrics):
                    alert.last_triggered = datetime.now()

                    triggered_alerts.append({
                        'alert_id': alert_id,
                        'name': alert.name,
                        'severity': alert.severity.value,
                        'message': alert.message_template,
                        'timestamp': datetime.now().isoformat()
                    })

                    self.logger.warning(
                        f"Alert triggered: {alert.name} ({alert.severity.value})"
                    )

            except Exception as e:
                self.logger.error(f"Alert check failed for {alert.name}: {str(e)}")

        return triggered_alerts

    def get_health_status(self) -> Dict:
        """
        Get overall system health

        Returns:
            Health status summary
        """
        # Get recent metrics
        recent_time = datetime.now() - timedelta(minutes=5)
        recent_metrics = self.metrics.get_metrics(start_time=recent_time)

        # Calculate health indicators
        total_predictions = sum(
            1 for m in recent_metrics
            if m.name == 'prediction_count'
        )

        total_errors = sum(
            m.value for m in recent_metrics
            if m.name == 'error_count'
        )

        error_rate = total_errors / total_predictions if total_predictions > 0 else 0

        # Determine status
        if error_rate > 0.1:
            status = "unhealthy"
        elif error_rate > 0.05:
            status = "degraded"
        else:
            status = "healthy"

        return {
            'status': status,
            'total_predictions': total_predictions,
            'total_errors': total_errors,
            'error_rate': error_rate,
            'timestamp': datetime.now().isoformat()
        }

\section{Data Drift Detection}

\subsection{Types of Drift}

Data drift occurs when the statistical properties of production data diverge from training data, degrading model performance.

\textbf{Drift categories:}
\begin{itemize}
    \item \textbf{Covariate drift:} Input feature distributions change ($P(X)$ changes)
    \item \textbf{Concept drift:} Relationship between features and target changes ($P(Y|X)$ changes)
    \item \textbf{Label drift:} Target distribution changes ($P(Y)$ changes)
    \item \textbf{Prediction drift:} Model predictions distribution changes
\end{itemize}

\subsection{Drift Detection with Evidently and Custom Methods}

from dataclasses import dataclass
from typing import Dict, List, Tuple
import logging
import pandas as pd
import numpy as np
from scipy import stats
from scipy.spatial.distance import jensenshannon
import warnings

@dataclass
class DriftResult:
    """Result of drift detection"""
    feature_name: str
    drift_detected: bool
    drift_score: float
    p_value: float
    method: str
    threshold: float
    reference_stats: Dict[str, float]
    current_stats: Dict[str, float]

class DriftDetector:
    """
    Comprehensive drift detection system

    Implements multiple statistical tests for drift detection
    """

    def __init__(self, significance_level: float = 0.05):
        """
        Initialize drift detector

        Args:
            significance_level: Statistical significance threshold
        """
        self.significance_level = significance_level
        self.logger = logging.getLogger("DriftDetector")

    def detect_drift_ks(self,
                       reference_data: pd.Series,
                       current_data: pd.Series) -> DriftResult:
        """
        Kolmogorov-Smirnov test for continuous features

        Args:
            reference_data: Training/reference data
            current_data: Current production data

        Returns:
            Drift detection result
        """
        # Perform KS test
        statistic, p_value = stats.ks_2samp(reference_data, current_data)

        drift_detected = p_value < self.significance_level

        # Calculate statistics
        ref_stats = {
            'mean': float(reference_data.mean()),
            'std': float(reference_data.std()),
            'min': float(reference_data.min()),
            'max': float(reference_data.max()),
            'median': float(reference_data.median())
        }

        curr_stats = {
            'mean': float(current_data.mean()),
            'std': float(current_data.std()),
            'min': float(current_data.min()),
            'max': float(current_data.max()),
            'median': float(current_data.median())
        }

        return DriftResult(
            feature_name=reference_data.name if hasattr(reference_data, 'name') else 'unnamed',
            drift_detected=drift_detected,
            drift_score=statistic,
            p_value=p_value,
            method='Kolmogorov-Smirnov',
            threshold=self.significance_level,
            reference_stats=ref_stats,
            current_stats=curr_stats
        )

    def detect_drift_chi2(self,
                         reference_data: pd.Series,
                         current_data: pd.Series,
                         bins: int = 10) -> DriftResult:
        """
        Chi-squared test for categorical or binned continuous features

        Args:
            reference_data: Training/reference data
            current_data: Current production data
            bins: Number of bins for continuous data

        Returns:
            Drift detection result
        """
        # Create contingency table
        if reference_data.dtype in ['object', 'category']:
            # Categorical data
            ref_counts = reference_data.value_counts()
            curr_counts = current_data.value_counts()

            # Align categories
            all_categories = set(ref_counts.index) | set(curr_counts.index)
            ref_freq = [ref_counts.get(cat, 0) for cat in all_categories]
            curr_freq = [curr_counts.get(cat, 0) for cat in all_categories]

        else:
            # Continuous data - bin it
            combined = pd.concat([reference_data, current_data])
            bins_edges = pd.cut(combined, bins=bins, retbins=True)[1]

            ref_freq, _ = np.histogram(reference_data, bins=bins_edges)
            curr_freq, _ = np.histogram(current_data, bins=bins_edges)

        # Normalize to frequencies
        ref_freq = np.array(ref_freq) / np.sum(ref_freq)
        curr_freq = np.array(curr_freq) / np.sum(curr_freq)

        # Chi-squared test
        # Add small constant to avoid division by zero
        expected = (ref_freq + 1e-10) * len(current_data)
        observed = (curr_freq + 1e-10) * len(current_data)

        chi2_stat = np.sum((observed - expected) ** 2 / expected)
        dof = len(ref_freq) - 1
        p_value = 1 - stats.chi2.cdf(chi2_stat, dof)

        drift_detected = p_value < self.significance_level

        ref_stats = {
            'unique_values': len(reference_data.unique()),
            'mode': reference_data.mode()[0] if len(reference_data.mode()) > 0 else None
        }

        curr_stats = {
            'unique_values': len(current_data.unique()),
            'mode': current_data.mode()[0] if len(current_data.mode()) > 0 else None
        }

        return DriftResult(
            feature_name=reference_data.name if hasattr(reference_data, 'name') else 'unnamed',
            drift_detected=drift_detected,
            drift_score=chi2_stat,
            p_value=p_value,
            method='Chi-Squared',
            threshold=self.significance_level,
            reference_stats=ref_stats,
            current_stats=curr_stats
        )

    def detect_drift_psi(self,
                        reference_data: pd.Series,
                        current_data: pd.Series,
                        bins: int = 10,
                        psi_threshold: float = 0.2) -> DriftResult:
        """
        Population Stability Index (PSI) for drift detection

        Args:
            reference_data: Training/reference data
            current_data: Current production data
            bins: Number of bins
            psi_threshold: PSI threshold (0.1=small, 0.2=medium, 0.25+=large shift)

        Returns:
            Drift detection result
        """
        # Create bins based on reference data
        if reference_data.dtype in ['object', 'category']:
            # Categorical
            ref_counts = reference_data.value_counts(normalize=True)
            curr_counts = current_data.value_counts(normalize=True)

            all_categories = set(ref_counts.index) | set(curr_counts.index)
            ref_pct = np.array([ref_counts.get(cat, 1e-10) for cat in all_categories])
            curr_pct = np.array([curr_counts.get(cat, 1e-10) for cat in all_categories])

        else:
            # Continuous - create bins
            bins_edges = pd.qcut(reference_data, q=bins, duplicates='drop', retbins=True)[1]

            ref_binned = pd.cut(reference_data, bins=bins_edges, include_lowest=True)
            curr_binned = pd.cut(current_data, bins=bins_edges, include_lowest=True)

            ref_pct = ref_binned.value_counts(normalize=True, sort=False).values
            curr_pct = curr_binned.value_counts(normalize=True, sort=False).values

        # Calculate PSI
        # PSI = sum((curr_pct - ref_pct) * ln(curr_pct / ref_pct))
        psi = np.sum((curr_pct - ref_pct) * np.log(curr_pct / ref_pct))

        drift_detected = abs(psi) > psi_threshold

        return DriftResult(
            feature_name=reference_data.name if hasattr(reference_data, 'name') else 'unnamed',
            drift_detected=drift_detected,
            drift_score=abs(psi),
            p_value=0.0,  # PSI doesn't have p-value
            method='PSI',
            threshold=psi_threshold,
            reference_stats={'mean': float(reference_data.mean())},
            current_stats={'mean': float(current_data.mean())}
        )

    def detect_drift_jensen_shannon(self,
                                   reference_data: pd.Series,
                                   current_data: pd.Series,
                                   bins: int = 50) -> DriftResult:
        """
        Jensen-Shannon divergence for drift detection

        Args:
            reference_data: Training/reference data
            current_data: Current production data
            bins: Number of bins for histogram

        Returns:
            Drift detection result
        """
        # Create histograms
        if reference_data.dtype in ['object', 'category']:
            ref_counts = reference_data.value_counts(normalize=True)
            curr_counts = current_data.value_counts(normalize=True)

            all_categories = sorted(set(ref_counts.index) | set(curr_counts.index))
            ref_dist = np.array([ref_counts.get(cat, 1e-10) for cat in all_categories])
            curr_dist = np.array([curr_counts.get(cat, 1e-10) for cat in all_categories])

        else:
            # Continuous data
            combined = pd.concat([reference_data, current_data])
            bins_edges = np.histogram_bin_edges(combined, bins=bins)

            ref_hist, _ = np.histogram(reference_data, bins=bins_edges, density=True)
            curr_hist, _ = np.histogram(current_data, bins=bins_edges, density=True)

            ref_dist = ref_hist / (ref_hist.sum() + 1e-10)
            curr_dist = curr_hist / (curr_hist.sum() + 1e-10)

        # Calculate Jensen-Shannon divergence
        js_divergence = jensenshannon(ref_dist, curr_dist)

        # JS divergence ranges from 0 (identical) to 1 (completely different)
        # Threshold: 0.1 = small drift, 0.3 = significant drift
        drift_detected = js_divergence > 0.1

        return DriftResult(
            feature_name=reference_data.name if hasattr(reference_data, 'name') else 'unnamed',
            drift_detected=drift_detected,
            drift_score=js_divergence,
            p_value=0.0,  # JS doesn't have p-value
            method='Jensen-Shannon',
            threshold=0.1,
            reference_stats={'mean': float(reference_data.mean())} if reference_data.dtype != 'object' else {},
            current_stats={'mean': float(current_data.mean())} if current_data.dtype != 'object' else {}
        )

class DataDriftMonitor:
    """
    Monitor data drift across all features

    Provides comprehensive drift monitoring for ML systems
    """

    def __init__(self,
                 reference_data: pd.DataFrame,
                 detector: DriftDetector = None):
        """
        Initialize drift monitor

        Args:
            reference_data: Reference/training dataset
            detector: Drift detector (creates default if None)
        """
        self.reference_data = reference_data
        self.detector = detector or DriftDetector()
        self.drift_history: List[Dict] = []
        self.logger = logging.getLogger("DataDriftMonitor")

    def check_drift(self,
                   current_data: pd.DataFrame,
                   method: str = 'auto') -> Dict[str, DriftResult]:
        """
        Check drift for all features

        Args:
            current_data: Current production data
            method: Detection method ('ks', 'chi2', 'psi', 'js', 'auto')

        Returns:
            Dictionary of drift results by feature
        """
        drift_results = {}

        for column in self.reference_data.columns:
            if column not in current_data.columns:
                self.logger.warning(f"Column {column} not in current data")
                continue

            ref_col = self.reference_data[column]
            curr_col = current_data[column]

            # Auto-select method based on data type
            if method == 'auto':
                if ref_col.dtype in ['object', 'category']:
                    detection_method = 'chi2'
                else:
                    detection_method = 'ks'
            else:
                detection_method = method

            # Detect drift
            try:
                if detection_method == 'ks':
                    result = self.detector.detect_drift_ks(ref_col, curr_col)
                elif detection_method == 'chi2':
                    result = self.detector.detect_drift_chi2(ref_col, curr_col)
                elif detection_method == 'psi':
                    result = self.detector.detect_drift_psi(ref_col, curr_col)
                elif detection_method == 'js':
                    result = self.detector.detect_drift_jensen_shannon(ref_col, curr_col)
                else:
                    raise ValueError(f"Unknown method: {detection_method}")

                drift_results[column] = result

                if result.drift_detected:
                    self.logger.warning(
                        f"Drift detected in {column}: "
                        f"score={result.drift_score:.4f}, p-value={result.p_value:.4f}"
                    )

            except Exception as e:
                self.logger.error(f"Drift detection failed for {column}: {str(e)}")

        # Store in history
        self.drift_history.append({
            'timestamp': datetime.now(),
            'results': drift_results,
            'drift_count': sum(1 for r in drift_results.values() if r.drift_detected)
        })

        return drift_results

    def get_drift_report(self) -> pd.DataFrame:
        """
        Generate drift report

        Returns:
            DataFrame with drift summary
        """
        if not self.drift_history:
            return pd.DataFrame()

        latest = self.drift_history[-1]
        results = latest['results']

        report_data = []
        for feature, result in results.items():
            report_data.append({
                'feature': feature,
                'drift_detected': result.drift_detected,
                'drift_score': result.drift_score,
                'p_value': result.p_value,
                'method': result.method,
                'ref_mean': result.reference_stats.get('mean', None),
                'curr_mean': result.current_stats.get('mean', None),
                'mean_change_pct': (
                    ((result.current_stats.get('mean', 0) - result.reference_stats.get('mean', 0)) /
                     abs(result.reference_stats.get('mean', 1))) * 100
                    if result.reference_stats.get('mean') else None
                )
            })

        return pd.DataFrame(report_data)

from dataclasses import dataclass
from typing import Any, Dict, List
from datetime import datetime, timedelta
import logging
import numpy as np
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score
from sklearn.metrics import mean_absolute_error, mean_squared_error

@dataclass
class PerformanceSnapshot:
    """Snapshot of model performance"""
    timestamp: datetime
    model_name: str
    model_version: str
    metrics: Dict[str, float]
    sample_count: int
    evaluation_window: str

class PerformanceMonitor:
    """
    Monitor model performance over time

    Tracks performance metrics and detects degradation
    """

    def __init__(self,
                 metrics_collector: MetricsCollector,
                 performance_window_hours: int = 24):
        """
        Initialize performance monitor

        Args:
            metrics_collector: Metrics collector instance
            performance_window_hours: Window for performance calculation
        """
        self.metrics = metrics_collector
        self.window_hours = performance_window_hours
        self.predictions_buffer: List[Dict] = []
        self.ground_truth_buffer: List[Dict] = []
        self.performance_history: List[PerformanceSnapshot] = []
        self.logger = logging.getLogger("PerformanceMonitor")

    def record_prediction(self,
                         model_name: str,
                         model_version: str,
                         prediction_id: str,
                         features: Dict,
                         prediction: Any,
                         timestamp: datetime = None):
        """
        Record a prediction for later evaluation

        Args:
            model_name: Model name
            model_version: Model version
            prediction_id: Unique prediction ID
            features: Input features
            prediction: Model prediction
            timestamp: Prediction timestamp
        """
        self.predictions_buffer.append({
            'prediction_id': prediction_id,
            'model_name': model_name,
            'model_version': model_version,
            'prediction': prediction,
            'features': features,
            'timestamp': timestamp or datetime.now()
        })

    def record_ground_truth(self,
                           prediction_id: str,
                           actual: Any,
                           timestamp: datetime = None):
        """
        Record ground truth for a prediction

        Args:
            prediction_id: Prediction ID
            actual: Actual value
            timestamp: Ground truth timestamp
        """
        self.ground_truth_buffer.append({
            'prediction_id': prediction_id,
            'actual': actual,
            'timestamp': timestamp or datetime.now()
        })

        # Try to evaluate
        self._evaluate_if_ready()

    def _evaluate_if_ready(self):
        """Evaluate performance if enough ground truth available"""
        # Match predictions with ground truth
        matched_pairs = []

        pred_dict = {p['prediction_id']: p for p in self.predictions_buffer}
        gt_dict = {g['prediction_id']: g for g in self.ground_truth_buffer}

        for pred_id in pred_dict.keys() & gt_dict.keys():
            pred = pred_dict[pred_id]
            gt = gt_dict[pred_id]

            # Check if within window
            time_diff = abs((pred['timestamp'] - gt['timestamp']).total_seconds() / 3600)
            if time_diff <= self.window_hours:
                matched_pairs.append({
                    'model_name': pred['model_name'],
                    'model_version': pred['model_version'],
                    'prediction': pred['prediction'],
                    'actual': gt['actual'],
                    'timestamp': pred['timestamp']
                })

        # If enough matched pairs, calculate metrics
        if len(matched_pairs) >= 100:  # Minimum sample size
            self._calculate_performance_metrics(matched_pairs)

            # Clear old buffers
            cutoff_time = datetime.now() - timedelta(hours=self.window_hours * 2)
            self.predictions_buffer = [
                p for p in self.predictions_buffer
                if p['timestamp'] > cutoff_time
            ]
            self.ground_truth_buffer = [
                g for g in self.ground_truth_buffer
                if g['timestamp'] > cutoff_time
            ]

    def _calculate_performance_metrics(self, matched_pairs: List[Dict]):
        """Calculate performance metrics from matched pairs"""
        if not matched_pairs:
            return

        # Group by model
        from collections import defaultdict
        by_model = defaultdict(list)

        for pair in matched_pairs:
            key = (pair['model_name'], pair['model_version'])
            by_model[key].append(pair)

        # Calculate metrics for each model
        for (model_name, model_version), pairs in by_model.items():
            predictions = [p['prediction'] for p in pairs]
            actuals = [p['actual'] for p in pairs]

            # Detect task type
            is_classification = isinstance(predictions[0], (str, int, bool))

            if is_classification:
                metrics = self._calculate_classification_metrics(
                    predictions, actuals
                )
            else:
                metrics = self._calculate_regression_metrics(
                    predictions, actuals
                )

            # Create snapshot
            snapshot = PerformanceSnapshot(
                timestamp=datetime.now(),
                model_name=model_name,
                model_version=model_version,
                metrics=metrics,
                sample_count=len(pairs),
                evaluation_window=f"{self.window_hours}h"
            )

            self.performance_history.append(snapshot)

            # Log metrics
            labels = {
                'model_name': model_name,
                'model_version': model_version
            }

            for metric_name, value in metrics.items():
                self.metrics.record_gauge(
                    f'model_{metric_name}',
                    value=value,
                    labels=labels
                )

            self.logger.info(
                f"Performance calculated for {model_name} v{model_version}: {metrics}"
            )

    def _calculate_classification_metrics(self,
                                         predictions: List,
                                         actuals: List) -> Dict[str, float]:
        """Calculate classification metrics"""
        try:
            return {
                'accuracy': accuracy_score(actuals, predictions),
                'precision': precision_score(actuals, predictions, average='weighted', zero_division=0),
                'recall': recall_score(actuals, predictions, average='weighted', zero_division=0),
                'f1_score': f1_score(actuals, predictions, average='weighted', zero_division=0)
            }
        except Exception as e:
            self.logger.error(f"Classification metrics calculation failed: {str(e)}")
            return {}

    def _calculate_regression_metrics(self,
                                     predictions: List,
                                     actuals: List) -> Dict[str, float]:
        """Calculate regression metrics"""
        try:
            predictions = np.array(predictions)
            actuals = np.array(actuals)

            mae = mean_absolute_error(actuals, predictions)
            mse = mean_squared_error(actuals, predictions)
            rmse = np.sqrt(mse)

            # R-squared
            ss_res = np.sum((actuals - predictions) ** 2)
            ss_tot = np.sum((actuals - np.mean(actuals)) ** 2)
            r2 = 1 - (ss_res / ss_tot) if ss_tot != 0 else 0

            return {
                'mae': mae,
                'mse': mse,
                'rmse': rmse,
                'r_squared': r2
            }
        except Exception as e:
            self.logger.error(f"Regression metrics calculation failed: {str(e)}")
            return {}

    def get_performance_trend(self,
                             model_name: str,
                             metric_name: str,
                             window_snapshots: int = 10) -> List[float]:
        """
        Get performance trend for a metric

        Args:
            model_name: Model name
            metric_name: Metric to track
            window_snapshots: Number of recent snapshots

        Returns:
            List of metric values over time
        """
        relevant_snapshots = [
            s for s in self.performance_history[-window_snapshots:]
            if s.model_name == model_name and metric_name in s.metrics
        ]

        return [s.metrics[metric_name] for s in relevant_snapshots]

    def detect_performance_degradation(self,
                                      model_name: str,
                                      metric_name: str,
                                      threshold_pct: float = 5.0) -> bool:
        """
        Detect if performance has degraded

        Args:
            model_name: Model name
            metric_name: Metric to check
            threshold_pct: Degradation threshold (percentage)

        Returns:
            True if degradation detected
        """
        trend = self.get_performance_trend(model_name, metric_name, window_snapshots=20)

        if len(trend) < 5:
            return False

        # Compare recent vs historical
        recent_avg = np.mean(trend[-5:])
        historical_avg = np.mean(trend[:-5])

        pct_change = ((recent_avg - historical_avg) / abs(historical_avg)) * 100

        # For metrics where higher is better (accuracy, f1, r2)
        better_higher = metric_name in ['accuracy', 'f1_score', 'precision', 'recall', 'r_squared']

        if better_higher:
            return pct_change < -threshold_pct
        else:
            return pct_change > threshold_pct

\section{Alert Systems and Incident Response}

\subsection{Intelligent Alerting}

Effective alerting balances sensitivity (catching real issues) with specificity (avoiding false alarms). ML systems require specialized alerting strategies that account for gradual degradation and statistical variation.

\textbf{Alerting principles:}
\begin{itemize}
    \item \textbf{Actionable alerts:} Every alert should require human action
    \item \textbf{Context-rich:} Include enough information for diagnosis
    \item \textbf{Prioritized:} Clear severity levels guide response
    \item \textbf{Deduplicated:} Avoid alert storms from correlated issues
    \item \textbf{Adaptive thresholds:} Account for normal variation patterns
\end{itemize}

        self.logger.info(
            f"Registered runbook for {alert_type} with {len(actions)} actions"
        )

        """Execute runbook actions"""
        if alert_type not in self.runbooks:
            self.logger.warning(f"No runbook for {alert_type}")
            return []

        results = []
        actions = self.runbooks[alert_type]

        for i, action in enumerate(actions):
            try:
                self.logger.info(
                    f"Executing runbook action {i+1}/{len(actions)} for {alert_type}"
                )
                result = action(context)
                results.append({
                    'action_index': i,
                    'status': 'success',
                    'result': result,
                    'timestamp': datetime.now().isoformat()
                })
            except Exception as e:
                self.logger.error(f"Runbook action {i+1} failed: {str(e)}")
                results.append({
                    'action_index': i,
                    'status': 'failed',
                    'error': str(e),
                    'timestamp': datetime.now().isoformat()
                })

        return results

class MLLogger:
    """
    Structured logger for ML systems

    Captures prediction context, model metadata, and performance info
    with machine-parseable JSON format
    """

    def __init__(self, service_name: str, log_file: Optional[str] = None):
        self.service_name = service_name
        self.logger = logging.getLogger(service_name)
        self.logger.setLevel(logging.INFO)

        # JSON formatter
        handler = logging.FileHandler(log_file) if log_file else logging.StreamHandler()
        self.logger.addHandler(handler)

    def _create_log_entry(self, level: LogLevel, event: str,
                         context: Dict[str, Any]) -> Dict[str, Any]:
        """Create structured log entry"""
        return {
            'timestamp': datetime.now().isoformat(),
            'service': self.service_name,
            'level': level.value,
            'event': event,
            'context': context
        }

    def log_prediction(self, model_name: str, model_version: str,
                      prediction_id: str, features: Dict,
                      prediction: Any, confidence: float,
                      latency_ms: float):
        """Log ML prediction with full context"""

        # Hash features for privacy
        feature_hash = hashlib.sha256(
            json.dumps(features, sort_keys=True).encode()
        ).hexdigest()[:16]

        log_entry = self._create_log_entry(
            level=LogLevel.INFO,
            event='ml_prediction',
            context={
                'model_name': model_name,
                'model_version': model_version,
                'prediction_id': prediction_id,
                'feature_hash': feature_hash,
                'prediction': str(prediction),
                'confidence': confidence,
                'latency_ms': latency_ms,
                'feature_count': len(features)
            }
        )

        self.logger.info(json.dumps(log_entry))

    def log_drift_detection(self, feature_name: str, drift_score: float,
                           drift_detected: bool, method: str):
        """Log drift detection results"""

        log_entry = self._create_log_entry(
            level=LogLevel.WARNING if drift_detected else LogLevel.INFO,
            event='drift_detection',
            context={
                'feature_name': feature_name,
                'drift_score': drift_score,
                'drift_detected': drift_detected,
                'detection_method': method
            }
        )

        self.logger.warning(json.dumps(log_entry)) if drift_detected \
            else self.logger.info(json.dumps(log_entry))

    def log_model_error(self, model_name: str, model_version: str,
                       error_type: str, error_message: str,
                       prediction_id: Optional[str] = None):
        """Log model errors with context"""

        log_entry = self._create_log_entry(

            event='model_error',
            context={
                'model_name': model_name,
                'model_version': model_version,
                'error_type': error_type,
                'error_message': error_message,
                'prediction_id': prediction_id
            }

                'model_version': model_version,
                'metrics': metrics,
                'window_hours': window_hours
            }
        )

        self.logger.info(json.dumps(log_entry))

resource = Resource(attributes={

class TracedMLPipeline:
    """ML serving pipeline with distributed tracing"""

    def __init__(self, model_name: str):
        self.model_name = model_name
        self.tracer = trace.get_tracer(__name__)

    def predict(self, features: Dict[str, Any]) -> Dict[str, Any]:
        """Execute prediction with full tracing"""

        # Create root span for the prediction request
        with self.tracer.start_as_current_span("ml_prediction") as span:
            span.set_attribute("model.name", self.model_name)
            span.set_attribute("feature.count", len(features))

            try:
                # Step 1: Validate input
                validated = self._validate_input(features)

                # Step 2: Preprocess features
                processed = self._preprocess(validated)

                # Step 3: Run inference
                prediction = self._inference(processed)

                # Step 4: Postprocess results
                result = self._postprocess(prediction)

                span.set_attribute("prediction.confidence", result['confidence'])
                span.set_attribute("prediction.class", result['class'])

                return result

            except Exception as e:
                span.record_exception(e)
                span.set_status(trace.Status(trace.StatusCode.ERROR))
                raise

    def _validate_input(self, features: Dict[str, Any]) -> Dict[str, Any]:
        """Validate input features"""
        with self.tracer.start_as_current_span("validate_input") as span:
            start = time.time()

            # Validation logic
            required_features = ['age', 'income', 'credit_score']
            missing = [f for f in required_features if f not in features]

            if missing:
                span.set_attribute("validation.failed", True)
                span.set_attribute("missing_features", ','.join(missing))
                raise ValueError(f"Missing features: {missing}")

            span.set_attribute("validation.duration_ms",
                             (time.time() - start) * 1000)
            return features

    def _preprocess(self, features: Dict[str, Any]) -> Dict[str, Any]:
        """Preprocess features"""
        with self.tracer.start_as_current_span("preprocess_features") as span:
            start = time.time()

            # Simulate preprocessing
            processed = {
                'age_normalized': features['age'] / 100,
                'income_log': np.log1p(features['income']),
                'credit_normalized': features['credit_score'] / 850
            }

            span.set_attribute("preprocessing.duration_ms",
                             (time.time() - start) * 1000)
            span.set_attribute("preprocessing.method", "standard_scaler")

            return processed

    def _inference(self, features: Dict[str, Any]) -> Dict[str, Any]:
        """Run model inference"""
        with self.tracer.start_as_current_span("model_inference") as span:
            start = time.time()

            # Simulate model inference
            time.sleep(0.05)  # Model execution time

            prediction = {
                'class': 1,
                'probability': 0.87
            }

            inference_time = (time.time() - start) * 1000
            span.set_attribute("inference.duration_ms", inference_time)
            span.set_attribute("inference.batch_size", 1)

            return prediction

    def _postprocess(self, prediction: Dict[str, Any]) -> Dict[str, Any]:
        """Postprocess predictions"""
        with self.tracer.start_as_current_span("postprocess_results") as span:
            start = time.time()

            # Add business logic
            result = {
                'class': prediction['class'],
                'confidence': prediction['probability'],
                'risk_level': 'high' if prediction['probability'] > 0.8 else 'low'
            }

            span.set_attribute("postprocessing.duration_ms",
                             (time.time() - start) * 1000)

            return result

\subsection{Data Quality Monitoring Implementation}

Data quality issues are the most common cause of ML failures in production. Comprehensive data quality monitoring detects schema violations, distribution shifts, and anomalies.

\begin{lstlisting}[language=Python, caption=Data Quality Monitoring System]
from typing import Dict, List, Set, Optional, Any
import pandas as pd
import numpy as np
from dataclasses import dataclass
from datetime import datetime
from scipy import stats

@dataclass
class DataQualityRule:
    """Define data quality validation rule"""
    feature_name: str
    rule_type: str  # 'range', 'categorical', 'not_null', 'pattern'
    parameters: Dict[str, Any]
    severity: str = 'error'  # 'error', 'warning', 'info'

@dataclass
class QualityViolation:
    """Data quality violation record"""
    feature_name: str
    rule_type: str
    severity: str
    violation_count: int
    violation_rate: float
    timestamp: datetime
    details: str

class DataQualityMonitor:
    """
    Monitor data quality for ML feature pipelines

    Validates schemas, detects anomalies, tracks data quality metrics
    """

    def __init__(self):
        self.rules: List[DataQualityRule] = []
        self.violations: List[QualityViolation] = []
        self.baseline_stats: Dict[str, Dict] = {}

    def add_rule(self, rule: DataQualityRule):
        """Add data quality rule"""
        self.rules.append(rule)

    def set_baseline(self, reference_data: pd.DataFrame):
        """Set baseline statistics from reference data"""
        for column in reference_data.columns:
            if pd.api.types.is_numeric_dtype(reference_data[column]):
                self.baseline_stats[column] = {
                    'mean': reference_data[column].mean(),
                    'std': reference_data[column].std(),
                    'min': reference_data[column].min(),
                    'max': reference_data[column].max(),
                    'q25': reference_data[column].quantile(0.25),
                    'q75': reference_data[column].quantile(0.75),
                    'null_rate': reference_data[column].isnull().mean()
                }
            else:
                self.baseline_stats[column] = {
                    'unique_values': set(reference_data[column].dropna().unique()),
                    'null_rate': reference_data[column].isnull().mean(),
                    'mode': reference_data[column].mode()[0] if len(reference_data[column].mode()) > 0 else None
                }

    def validate_batch(self, data: pd.DataFrame) -> List[QualityViolation]:
        """Validate data batch against quality rules"""
        violations = []

        # Check schema
        violations.extend(self._check_schema(data))

        # Check null rates
        violations.extend(self._check_nulls(data))

        # Check value ranges
        violations.extend(self._check_ranges(data))

        # Check categorical values
        violations.extend(self._check_categorical(data))

        # Check for anomalies
        violations.extend(self._check_anomalies(data))

        self.violations.extend(violations)
        return violations

    def _check_schema(self, data: pd.DataFrame) -> List[QualityViolation]:
        """Validate data schema"""
        violations = []

        expected_columns = set(self.baseline_stats.keys())
        actual_columns = set(data.columns)

        missing_cols = expected_columns - actual_columns
        extra_cols = actual_columns - expected_columns

        if missing_cols:
            violations.append(QualityViolation(
                feature_name='schema',
                rule_type='missing_columns',
                severity='error',
                violation_count=len(missing_cols),
                violation_rate=len(missing_cols) / len(expected_columns),
                timestamp=datetime.now(),
                details=f"Missing columns: {missing_cols}"
            ))

        if extra_cols:
            violations.append(QualityViolation(
                feature_name='schema',
                rule_type='extra_columns',
                severity='warning',
                violation_count=len(extra_cols),
                violation_rate=len(extra_cols) / len(expected_columns),
                timestamp=datetime.now(),
                details=f"Extra columns: {extra_cols}"
            ))

        return violations

    def _check_nulls(self, data: pd.DataFrame) -> List[QualityViolation]:
        """Check for excessive null values"""
        violations = []

        for column in data.columns:
            if column not in self.baseline_stats:
                continue

            null_rate = data[column].isnull().mean()
            baseline_null_rate = self.baseline_stats[column].get('null_rate', 0)

            # Alert if null rate increases by more than 50%
            if null_rate > baseline_null_rate * 1.5:
                violations.append(QualityViolation(
                    feature_name=column,
                    rule_type='high_null_rate',
                    severity='error' if null_rate > 0.5 else 'warning',
                    violation_count=int(data[column].isnull().sum()),
                    violation_rate=null_rate,
                    timestamp=datetime.now(),
                    details=f"Null rate {null_rate:.2%} vs baseline {baseline_null_rate:.2%}"
                ))

        return violations

    def _check_ranges(self, data: pd.DataFrame) -> List[QualityViolation]:
        """Check numeric values are within expected ranges"""
        violations = []

        for column in data.columns:
            if column not in self.baseline_stats:
                continue

            if 'min' not in self.baseline_stats[column]:
                continue

            baseline = self.baseline_stats[column]

            # Check for values outside baseline range
            out_of_range = (
                (data[column] < baseline['min']) |
                (data[column] > baseline['max'])
            ).sum()

            if out_of_range > 0:
                violations.append(QualityViolation(
                    feature_name=column,
                    rule_type='out_of_range',
                    severity='warning',
                    violation_count=int(out_of_range),
                    violation_rate=out_of_range / len(data),
                    timestamp=datetime.now(),
                    details=f"Values outside [{baseline['min']:.2f}, {baseline['max']:.2f}]"
                ))

        return violations

    def _check_categorical(self, data: pd.DataFrame) -> List[QualityViolation]:
        """Check categorical values match expected set"""
        violations = []

        for column in data.columns:
            if column not in self.baseline_stats:
                continue

            if 'unique_values' not in self.baseline_stats[column]:
                continue

            baseline_values = self.baseline_stats[column]['unique_values']
            current_values = set(data[column].dropna().unique())

            # New values not seen in baseline
            new_values = current_values - baseline_values

            if new_values:
                violations.append(QualityViolation(
                    feature_name=column,
                    rule_type='unexpected_categorical_value',
                    severity='warning',
                    violation_count=len(new_values),
                    violation_rate=len(new_values) / len(baseline_values) if baseline_values else 1.0,
                    timestamp=datetime.now(),
                    details=f"New categorical values: {new_values}"
                ))

        return violations

    def _check_anomalies(self, data: pd.DataFrame) -> List[QualityViolation]:
        """Detect statistical anomalies"""
        violations = []

        for column in data.columns:
            if column not in self.baseline_stats:
                continue

            if 'mean' not in self.baseline_stats[column]:
                continue

            baseline = self.baseline_stats[column]
            current_mean = data[column].mean()
            current_std = data[column].std()

            # Check if mean shifted significantly (>3 standard deviations)
            z_score = abs(current_mean - baseline['mean']) / baseline['std']

            if z_score > 3:
                violations.append(QualityViolation(
                    feature_name=column,
                    rule_type='mean_shift',
                    severity='warning',
                    violation_count=1,
                    violation_rate=z_score / 3,
                    timestamp=datetime.now(),
                    details=f"Mean shifted from {baseline['mean']:.2f} to {current_mean:.2f} (z-score: {z_score:.2f})"
                ))

        return violations

    def get_quality_report(self) -> Dict[str, Any]:
        """Generate data quality report"""
        if not self.violations:
            return {
                'status': 'healthy',
                'total_violations': 0,
                'violations_by_severity': {},
                'violations_by_type': {}
            }

        violations_by_severity = {}
        violations_by_type = {}

        for v in self.violations:
            violations_by_severity[v.severity] = violations_by_severity.get(v.severity, 0) + 1
            violations_by_type[v.rule_type] = violations_by_type.get(v.rule_type, 0) + 1

        return {
            'status': 'unhealthy' if 'error' in violations_by_severity else 'degraded',
            'total_violations': len(self.violations),
            'violations_by_severity': violations_by_severity,
            'violations_by_type': violations_by_type,
            'recent_violations': [
                {
                    'feature': v.feature_name,
                    'type': v.rule_type,
                    'severity': v.severity,
                    'details': v.details
                }
                for v in sorted(self.violations, key=lambda x: x.timestamp, reverse=True)[:10]
            ]
        }

\textbf{Problem:} Implement a custom drift detection system that combines multiple statistical methods (KS test, PSI, Jensen-Shannon divergence) and creates an ensemble score to make drift decisions more robust.

# Exercise 7 Solution
from typing import Dict, List, Tuple
from dataclasses import dataclass
from enum import Enum

class DriftSeverity(Enum):
    """Drift severity levels"""
    NONE = "none"
    LOW = "low"
    MEDIUM = "medium"
    HIGH = "high"
    CRITICAL = "critical"

@dataclass
class EnsembleDriftResult:
    """Result from ensemble drift detection"""
    feature_name: str
    ensemble_score: float
    severity: DriftSeverity
    individual_results: Dict[str, DriftResult]
    recommendation: str

class EnsembleDriftDetector:
    """
    Ensemble drift detector using multiple statistical methods

    Combines KS test, PSI, and Jensen-Shannon divergence for
    robust drift detection with configurable thresholds
    """

    def __init__(self,
                 ks_threshold: float = 0.05,
                 psi_threshold: float = 0.2,
                 js_threshold: float = 0.15,
                 ensemble_weights: Dict[str, float] = None):
        self.detector = DriftDetector()
        self.ks_threshold = ks_threshold
        self.psi_threshold = psi_threshold
        self.js_threshold = js_threshold

        # Default weights for ensemble
        self.weights = ensemble_weights or {
            'ks': 0.35,
            'psi': 0.35,
            'js': 0.30
        }

    def detect_ensemble_drift(self,
                            reference_data: pd.Series,
                            current_data: pd.Series,
                            feature_name: str) -> EnsembleDriftResult:
        """Detect drift using ensemble of methods"""

        # Run all detection methods
        ks_result = self.detector.detect_drift_ks(reference_data, current_data)
        psi_result = self.detector.detect_drift_psi(
            reference_data, current_data, psi_threshold=self.psi_threshold
        )
        js_result = self.detector.detect_drift_jensen_shannon(
            reference_data, current_data
        )

        # Store individual results
        individual_results = {
            'ks': ks_result,
            'psi': psi_result,
            'js': js_result
        }

        # Calculate normalized scores (0-1 scale)
        ks_score = 1 - ks_result.drift_score  # p-value: lower = more drift
        psi_score = min(psi_result.drift_score / 0.5, 1.0)  # normalize PSI
        js_score = min(js_result.drift_score / 0.5, 1.0)  # normalize JS

        # Weighted ensemble score
        ensemble_score = (
            self.weights['ks'] * ks_score +
            self.weights['psi'] * psi_score +
            self.weights['js'] * js_score
        )

        # Determine severity
        severity = self._calculate_severity(ensemble_score)

        # Generate recommendation
        recommendation = self._generate_recommendation(
            severity, individual_results, feature_name
        )

        return EnsembleDriftResult(
            feature_name=feature_name,
            ensemble_score=ensemble_score,
            severity=severity,
            individual_results=individual_results,
            recommendation=recommendation
        )

    def _calculate_severity(self, ensemble_score: float) -> DriftSeverity:
        """Calculate drift severity from ensemble score"""
        if ensemble_score < 0.2:
            return DriftSeverity.NONE
        elif ensemble_score < 0.4:
            return DriftSeverity.LOW
        elif ensemble_score < 0.6:
            return DriftSeverity.MEDIUM
        elif ensemble_score < 0.8:
            return DriftSeverity.HIGH
        else:
            return DriftSeverity.CRITICAL

    def _generate_recommendation(self,
                                severity: DriftSeverity,
                                individual_results: Dict[str, DriftResult],
                                feature_name: str) -> str:
        """Generate actionable recommendation"""

        if severity == DriftSeverity.NONE:
            return f"No action required for {feature_name}"

        elif severity == DriftSeverity.LOW:
            return f"Monitor {feature_name} closely; consider investigating if trend continues"

        elif severity == DriftSeverity.MEDIUM:
            return f"Investigate {feature_name} distribution change; may need model retraining soon"

        elif severity == DriftSeverity.HIGH:
            methods_detected = [
                name for name, result in individual_results.items()
                if result.drift_detected
            ]
            return f"ACTION REQUIRED: {feature_name} showing drift in {methods_detected}; schedule model retraining"

        else:  # CRITICAL
            return f"URGENT: Critical drift in {feature_name}; consider model rollback or immediate retraining"

    \item \textbf{Track lineage:} Connect metrics to specific model versions
    \item \textbf{Implement graceful degradation:} Plan for performance issues
    \item \textbf{Monitor the monitors:} Ensure monitoring systems are healthy
    \item \textbf{Regular review:} Periodically assess alert effectiveness
\end{enumerate}

\subsection{Common Pitfalls}

\begin{itemize}
    \item \textbf{Alert fatigue:} Too many low-value alerts reduce effectiveness
    \item \textbf{Delayed ground truth:} Long feedback loops prevent timely detection
    \item \textbf{Ignoring gradual drift:} Small changes accumulate to major issues
    \item \textbf{Single metric focus:} Monitor multiple performance dimensions
    \item \textbf{Missing context:} Alerts need actionable information
    \item \textbf{Over-sensitive drift detection:} Natural variation triggers false alerts
    \item \textbf{No baseline:} Insufficient reference data for comparison
\end{itemize}

\subsection{Production Checklist}

Before deploying monitoring to production:

\begin{enumerate}
    \item Metrics collection covers all critical dimensions
    \item Reference datasets established for drift detection
    \item Alert thresholds tuned with historical data
    \item Notification channels tested and working
    \item Runbooks documented and automated
    \item Dashboards created for key stakeholders
    \item Monitoring system itself is monitored
    \item Incident response procedures documented
    \item On-call rotation established
    \item Regular review cadence scheduled
\end{enumerate}

\subsection{Integration Points}

ML monitoring integrates with broader infrastructure:

\begin{itemize}
    \item \textbf{Model registry:} Track which models are deployed
    \item \textbf{Feature store:} Monitor feature pipeline health
    \item \textbf{CI/CD:} Trigger retraining or rollbacks
    \item \textbf{Incident management:} Create tickets automatically
    \item \textbf{Cost management:} Track inference spend
    \item \textbf{Compliance systems:} Audit model decisions
\end{itemize}

By implementing comprehensive monitoring and observability, teams can confidently operate ML systems at scale, detect issues before they impact users, and continuously improve model performance. The combination of metrics collection, drift detection, performance tracking, and intelligent alerting provides complete visibility into ML system health.

\section{Introduction}

ML systems face unique security challenges beyond traditional software security. Attackers can manipulate training data, exploit model vulnerabilities, steal intellectual property, or extract private information from models.

\textbf{ML Security Threat Landscape:}

\begin{itemize}
    \item \textbf{Data Poisoning:} Attackers inject malicious data into training sets
    \item \textbf{Adversarial Examples:} Carefully crafted inputs cause misclassification
    \item \textbf{Model Stealing:} Extracting model parameters through query access
    \item \textbf{Model Inversion:} Reconstructing training data from model outputs
    \item \textbf{Membership Inference:} Determining if data was in training set
    \item \textbf{Backdoor Attacks:} Embedding hidden behaviors triggered by specific inputs
    \item \textbf{Privacy Leakage:} Models reveal sensitive information about training data
\end{itemize}

\textbf{Security Requirements for ML Systems:}

\begin{enumerate}
    \item \textbf{Confidentiality:} Protect training data, model parameters, and predictions
    \item \textbf{Integrity:} Ensure models behave as intended without manipulation
    \item \textbf{Availability:} Prevent denial-of-service and resource exhaustion
    \item \textbf{Accountability:} Audit and trace all model interactions
    \item \textbf{Privacy:} Prevent leakage of sensitive information
\end{enumerate}

\section{Adversarial Attack Detection and Defense}

Adversarial attacks exploit the continuous, high-dimensional nature of ML input spaces to create inputs that fool models while appearing normal to humans.

\subsection{Adversarial Attack Types}

\textbf{Common Attack Methods:}

\begin{itemize}
    \item \textbf{FGSM (Fast Gradient Sign Method):} Single-step attack using gradient sign
    \item \textbf{PGD (Projected Gradient Descent):} Multi-step iterative attack
    \item \textbf{C\&W (Carlini-Wagner):} Optimization-based attack minimizing perturbation
    \item \textbf{DeepFool:} Finds minimal perturbation to decision boundary
    \item \textbf{One-Pixel Attack:} Modifies single pixel using differential evolution
\end{itemize}

#!/usr/bin/env python3
"""
Adversarial Attack Detection and Defense
Comprehensive framework for securing ML models against adversarial attacks
"""

import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Tuple, Dict, List
from dataclasses import dataclass

@dataclass
class AdversarialExample:
    """Adversarial example with metadata"""
    original_input: np.ndarray
    perturbed_input: np.ndarray
    original_prediction: int
    adversarial_prediction: int
    perturbation: np.ndarray
    perturbation_norm: float
    attack_method: str

class AdversarialAttackGenerator:
    """Generate adversarial examples for testing"""

    def __init__(self, model: nn.Module, device: str = "cpu"):
        self.model = model
        self.device = device
        self.model.eval()

    def fgsm_attack(
        self,
        image: torch.Tensor,
        label: torch.Tensor,
        epsilon: float = 0.3
    ) -> torch.Tensor:
        """Fast Gradient Sign Method attack"""

        image.requires_grad = True

        # Forward pass
        output = self.model(image)
        loss = F.cross_entropy(output, label)

        # Backward pass
        self.model.zero_grad()
        loss.backward()

        # Generate adversarial example
        data_grad = image.grad.data
        perturbed_image = image + epsilon * data_grad.sign()
        perturbed_image = torch.clamp(perturbed_image, 0, 1)

        return perturbed_image

    def pgd_attack(
        self,
        image: torch.Tensor,
        label: torch.Tensor,
        epsilon: float = 0.3,
        alpha: float = 0.01,
        num_iter: int = 40
    ) -> torch.Tensor:
        """Projected Gradient Descent attack"""

        perturbed_image = image.clone().detach()

        for i in range(num_iter):
            perturbed_image.requires_grad = True

            output = self.model(perturbed_image)
            loss = F.cross_entropy(output, label)

            self.model.zero_grad()
            loss.backward()

            # Update perturbation
            data_grad = perturbed_image.grad.data
            perturbed_image = perturbed_image.detach() + alpha * data_grad.sign()

            # Project back to epsilon ball
            perturbation = torch.clamp(perturbed_image - image, -epsilon, epsilon)
            perturbed_image = torch.clamp(image + perturbation, 0, 1).detach()

        return perturbed_image

    def generate_adversarial_example(
        self,
        image: np.ndarray,
        true_label: int,
        attack_type: str = "fgsm",
        epsilon: float = 0.3
    ) -> AdversarialExample:
        """Generate adversarial example with metadata"""

        # Convert to tensor
        image_tensor = torch.FloatTensor(image).unsqueeze(0).to(self.device)
        label_tensor = torch.LongTensor([true_label]).to(self.device)

        # Original prediction
        with torch.no_grad():
            original_output = self.model(image_tensor)
            original_pred = original_output.argmax(1).item()

        # Generate adversarial example
        if attack_type == "fgsm":
            perturbed_tensor = self.fgsm_attack(image_tensor, label_tensor, epsilon)
        elif attack_type == "pgd":
            perturbed_tensor = self.pgd_attack(image_tensor, label_tensor, epsilon)
        else:
            raise ValueError(f"Unknown attack type: {attack_type}")

        # Adversarial prediction
        with torch.no_grad():
            adv_output = self.model(perturbed_tensor)
            adv_pred = adv_output.argmax(1).item()

        # Calculate perturbation
        perturbation = (perturbed_tensor - image_tensor).cpu().numpy()
        perturbation_norm = np.linalg.norm(perturbation)

        return AdversarialExample(
            original_input=image,
            perturbed_input=perturbed_tensor.cpu().numpy().squeeze(),
            original_prediction=original_pred,
            adversarial_prediction=adv_pred,
            perturbation=perturbation.squeeze(),
            perturbation_norm=perturbation_norm,
            attack_method=attack_type
        )

class AdversarialDetector:
    """Detect adversarial examples at inference time"""

    def __init__(self, model: nn.Module, device: str = "cpu"):
        self.model = model
        self.device = device
        self.detection_methods = []

    def add_detection_method(self, method_name: str, threshold: float):
        """Add detection method with threshold"""
        self.detection_methods.append({
            "name": method_name,
            "threshold": threshold
        })

    def detect_by_prediction_confidence(
        self,
        image: torch.Tensor,
        confidence_threshold: float = 0.95
    ) -> Tuple[bool, float]:
        """Detect based on prediction confidence"""

        with torch.no_grad():
            output = self.model(image)
            probabilities = F.softmax(output, dim=1)
            max_prob = probabilities.max().item()

        # Adversarial examples often have lower confidence
        is_adversarial = max_prob < confidence_threshold

        return is_adversarial, max_prob

    def detect_by_input_gradient(
        self,
        image: torch.Tensor,
        label: torch.Tensor,
        gradient_threshold: float = 10.0
    ) -> Tuple[bool, float]:
        """Detect based on input gradient magnitude"""

        image.requires_grad = True

        output = self.model(image)
        loss = F.cross_entropy(output, label)

        self.model.zero_grad()
        loss.backward()

        gradient_norm = image.grad.data.norm().item()

        # Adversarial examples often have larger gradients
        is_adversarial = gradient_norm > gradient_threshold

        return is_adversarial, gradient_norm

    def detect_by_feature_squeezing(
        self,
        image: torch.Tensor,
        squeeze_threshold: float = 0.1
    ) -> Tuple[bool, float]:
        """Detect using feature squeezing"""

        # Bit-depth reduction (squeeze to fewer bits)
        squeezed_image = torch.round(image * 4) / 4

        # Compare predictions
        with torch.no_grad():
            original_output = self.model(image)
            squeezed_output = self.model(squeezed_image)

            original_pred = original_output.argmax(1)
            squeezed_pred = squeezed_output.argmax(1)

        # Calculate L1 difference in predictions
        pred_diff = torch.abs(
            F.softmax(original_output, dim=1) -
            F.softmax(squeezed_output, dim=1)
        ).sum().item()

        is_adversarial = pred_diff > squeeze_threshold

        return is_adversarial, pred_diff

    def ensemble_detection(
        self,
        image: torch.Tensor,
        label: torch.Tensor
    ) -> Dict:
        """Run multiple detection methods and aggregate"""

        results = {
            "is_adversarial": False,
            "detection_scores": {},
            "methods_triggered": 0
        }

        # Confidence-based detection
        is_adv_conf, conf_score = self.detect_by_prediction_confidence(image)
        results["detection_scores"]["confidence"] = conf_score
        if is_adv_conf:
            results["methods_triggered"] += 1

        # Gradient-based detection
        is_adv_grad, grad_score = self.detect_by_input_gradient(image, label)
        results["detection_scores"]["gradient"] = grad_score
        if is_adv_grad:
            results["methods_triggered"] += 1

        # Feature squeezing
        is_adv_squeeze, squeeze_score = self.detect_by_feature_squeezing(image)
        results["detection_scores"]["feature_squeezing"] = squeeze_score
        if is_adv_squeeze:
            results["methods_triggered"] += 1

        # Mark as adversarial if 2+ methods trigger
        results["is_adversarial"] = results["methods_triggered"] >= 2

        return results

class AdversarialDefense:
    """Implement defense mechanisms against adversarial attacks"""

    def __init__(self, model: nn.Module, device: str = "cpu"):
        self.model = model
        self.device = device

    def adversarial_training(
        self,
        train_loader,
        optimizer,
        epochs: int = 10,
        epsilon: float = 0.3
    ):
        """Train model with adversarial examples"""

        attacker = AdversarialAttackGenerator(self.model, self.device)

        for epoch in range(epochs):
            self.model.train()
            total_loss = 0

            for batch_idx, (data, target) in enumerate(train_loader):
                data, target = data.to(self.device), target.to(self.device)

                # Generate adversarial examples
                adv_data = attacker.fgsm_attack(data, target, epsilon)

                # Train on both clean and adversarial examples
                optimizer.zero_grad()

                # Clean loss
                clean_output = self.model(data)
                clean_loss = F.cross_entropy(clean_output, target)

                # Adversarial loss
                adv_output = self.model(adv_data)
                adv_loss = F.cross_entropy(adv_output, target)

                # Combined loss
                loss = 0.5 * clean_loss + 0.5 * adv_loss
                loss.backward()
                optimizer.step()

                total_loss += loss.item()

            print(f"Epoch {epoch+1}/{epochs}, Loss: {total_loss/len(train_loader):.4f}")

    def input_transformation(self, image: torch.Tensor) -> torch.Tensor:
        """Apply input transformations to remove adversarial perturbations"""

        # JPEG compression simulation
        compressed = torch.round(image * 255) / 255

        # Gaussian smoothing
        kernel_size = 3
        sigma = 1.0
        smoothed = self._gaussian_blur(compressed, kernel_size, sigma)

        # Bit-depth reduction
        squeezed = torch.round(smoothed * 4) / 4

        return squeezed

    def _gaussian_blur(
        self,
        image: torch.Tensor,
        kernel_size: int,
        sigma: float
    ) -> torch.Tensor:
        """Apply Gaussian blur"""

        # Create Gaussian kernel
        kernel = self._gaussian_kernel(kernel_size, sigma)
        kernel = kernel.to(image.device)

        # Apply convolution
        blurred = F.conv2d(
            image,
            kernel.unsqueeze(0).unsqueeze(0),
            padding=kernel_size // 2
        )

        return blurred

    def _gaussian_kernel(self, kernel_size: int, sigma: float) -> torch.Tensor:
        """Generate Gaussian kernel"""

        x = torch.arange(kernel_size).float() - kernel_size // 2
        gauss = torch.exp(-x.pow(2) / (2 * sigma ** 2))
        kernel = gauss.unsqueeze(0) * gauss.unsqueeze(1)
        kernel = kernel / kernel.sum()

        return kernel

    def certified_defense(
        self,
        image: torch.Tensor,
        num_samples: int = 100,
        sigma: float = 0.1
    ) -> Tuple[int, float]:
        """Randomized smoothing for certified robustness"""

        predictions = []

        with torch.no_grad():
            for _ in range(num_samples):
                # Add Gaussian noise
                noisy_image = image + torch.randn_like(image) * sigma
                noisy_image = torch.clamp(noisy_image, 0, 1)

                # Get prediction
                output = self.model(noisy_image)
                pred = output.argmax(1).item()
                predictions.append(pred)

        # Majority vote
        from collections import Counter
        vote_counts = Counter(predictions)
        predicted_class = vote_counts.most_common(1)[0][0]
        confidence = vote_counts[predicted_class] / num_samples

        return predicted_class, confidence

\section{Model Stealing and Inversion Protection}

Model stealing attacks extract model parameters or functionality through query access. Model inversion attacks reconstruct training data from model outputs.

#!/usr/bin/env python3
"""
Model Stealing and Inversion Protection
Techniques to protect ML models from extraction and data reconstruction
"""

import numpy as np
import torch
import torch.nn as nn
from typing import Dict, List, Tuple
from collections import defaultdict
from datetime import datetime, timedelta
import hashlib

class QueryMonitor:
    """Monitor and detect suspicious query patterns"""

    def __init__(
        self,
        max_queries_per_user: int = 1000,
        time_window_minutes: int = 60,
        similarity_threshold: float = 0.95
    ):
        self.max_queries_per_user = max_queries_per_user
        self.time_window = timedelta(minutes=time_window_minutes)
        self.similarity_threshold = similarity_threshold

        self.query_history = defaultdict(list)
        self.user_query_counts = defaultdict(int)

    def record_query(
        self,
        user_id: str,
        query_input: np.ndarray,
        timestamp: datetime = None
    ) -> Dict:
        """Record query and check for suspicious patterns"""

        if timestamp is None:
            timestamp = datetime.now()

        # Check rate limiting
        recent_queries = self._get_recent_queries(user_id, timestamp)

        if len(recent_queries) >= self.max_queries_per_user:
            return {
                "allowed": False,
                "reason": "rate_limit_exceeded",
                "queries_in_window": len(recent_queries)
            }

        # Check for similar queries (potential model extraction)
        if self._detect_similar_queries(user_id, query_input):
            return {
                "allowed": False,
                "reason": "suspicious_query_pattern",
                "details": "Too many similar queries detected"
            }

        # Record query
        query_hash = self._hash_input(query_input)
        self.query_history[user_id].append({
            "timestamp": timestamp,
            "query_hash": query_hash,
            "input_shape": query_input.shape
        })

        self.user_query_counts[user_id] += 1

        return {
            "allowed": True,
            "total_queries": self.user_query_counts[user_id]
        }

    def _get_recent_queries(
        self,
        user_id: str,
        current_time: datetime
    ) -> List[Dict]:
        """Get queries within time window"""

        cutoff_time = current_time - self.time_window

        recent = [
            q for q in self.query_history[user_id]
            if q["timestamp"] > cutoff_time
        ]

        # Clean old queries
        self.query_history[user_id] = recent

        return recent

    def _detect_similar_queries(
        self,
        user_id: str,
        query_input: np.ndarray,
        max_similar: int = 100
    ) -> bool:
        """Detect if too many similar queries from same user"""

        query_hash = self._hash_input(query_input)
        recent_queries = self.query_history[user_id]

        if len(recent_queries) < max_similar:
            return False

        # Check last N queries for similarity
        similar_count = sum(
            1 for q in recent_queries[-max_similar:]
            if q["query_hash"] == query_hash
        )

        # If >10% of recent queries are identical, flag as suspicious
        return similar_count > (max_similar * 0.1)

    def _hash_input(self, query_input: np.ndarray) -> str:
        """Hash input for similarity detection"""

        # Quantize input to reduce sensitivity
        quantized = np.round(query_input * 100).astype(np.int32)
        return hashlib.sha256(quantized.tobytes()).hexdigest()[:16]

class PredictionObfuscator:
    """Obfuscate model predictions to prevent information leakage"""

    def __init__(
        self,
        noise_scale: float = 0.1,
        rounding_precision: int = 2,
        top_k_only: int = None
    ):
        self.noise_scale = noise_scale
        self.rounding_precision = rounding_precision
        self.top_k_only = top_k_only

    def obfuscate_probabilities(
        self,
        probabilities: np.ndarray
    ) -> np.ndarray:
        """Add noise and limit precision of probability outputs"""

        # Add Laplace noise for differential privacy
        noisy_probs = probabilities + np.random.laplace(
            0, self.noise_scale, size=probabilities.shape
        )

        # Clip to valid probability range
        noisy_probs = np.clip(noisy_probs, 0, 1)

        # Renormalize
        noisy_probs = noisy_probs / noisy_probs.sum()

        # Round to limit precision
        rounded_probs = np.round(noisy_probs, self.rounding_precision)

        # Renormalize again after rounding
        rounded_probs = rounded_probs / rounded_probs.sum()

        return rounded_probs

    def obfuscate_top_k(
        self,
        probabilities: np.ndarray,
        k: int = None
    ) -> np.ndarray:
        """Return only top-k predictions to limit information leakage"""

        if k is None:
            k = self.top_k_only

        if k is None:
            return probabilities

        # Get top-k indices
        top_k_indices = np.argsort(probabilities)[-k:]

        # Create sparse output
        obfuscated = np.zeros_like(probabilities)
        obfuscated[top_k_indices] = probabilities[top_k_indices]

        # Renormalize
        obfuscated = obfuscated / obfuscated.sum()

        return obfuscated

    def obfuscate_prediction(
        self,
        probabilities: np.ndarray,
        return_class_only: bool = False
    ) -> np.ndarray:
        """Apply full obfuscation pipeline"""

        # Add noise and round
        obfuscated = self.obfuscate_probabilities(probabilities)

        # Limit to top-k if specified
        if self.top_k_only:
            obfuscated = self.obfuscate_top_k(obfuscated, self.top_k_only)

        # Return only predicted class (maximum information hiding)
        if return_class_only:
            predicted_class = np.argmax(obfuscated)
            result = np.zeros_like(obfuscated)
            result[predicted_class] = 1.0
            return result

        return obfuscated

class ModelInversionDefense:
    """Defend against model inversion attacks"""

    def __init__(self, model: nn.Module):
        self.model = model

    def add_differential_privacy_noise(
        self,
        gradients: torch.Tensor,
        epsilon: float = 1.0,
        delta: float = 1e-5
    ) -> torch.Tensor:
        """Add DP noise to gradients during training"""

        # Calculate noise scale for (epsilon, delta)-DP
        sensitivity = 1.0  # L2 sensitivity of gradients
        noise_scale = sensitivity * np.sqrt(2 * np.log(1.25 / delta)) / epsilon

        # Add Gaussian noise
        noise = torch.randn_like(gradients) * noise_scale
        private_gradients = gradients + noise

        return private_gradients

    def gradient_clipping(
        self,
        gradients: torch.Tensor,
        max_norm: float = 1.0
    ) -> torch.Tensor:
        """Clip gradients to bound sensitivity"""

        grad_norm = gradients.norm(2)

        if grad_norm > max_norm:
            gradients = gradients * (max_norm / grad_norm)

        return gradients

    def prevent_overfitting_to_individuals(
        self,
        train_loader,
        validation_loader,
        optimizer,
        max_epochs: int = 100,
        early_stopping_patience: int = 10
    ):
        """Train with early stopping to prevent memorization"""

        best_val_loss = float('inf')
        patience_counter = 0

        for epoch in range(max_epochs):
            # Training
            self.model.train()
            train_loss = 0

            for data, target in train_loader:
                optimizer.zero_grad()
                output = self.model(data)
                loss = nn.CrossEntropyLoss()(output, target)
                loss.backward()
                optimizer.step()
                train_loss += loss.item()

            # Validation
            self.model.eval()
            val_loss = 0

            with torch.no_grad():
                for data, target in validation_loader:
                    output = self.model(data)
                    loss = nn.CrossEntropyLoss()(output, target)
                    val_loss += loss.item()

            val_loss /= len(validation_loader)

            # Early stopping check
            if val_loss < best_val_loss:
                best_val_loss = val_loss
                patience_counter = 0
            else:
                patience_counter += 1

            if patience_counter >= early_stopping_patience:
                print(f"Early stopping at epoch {epoch}")
                break

class SecureModelAPI:
    """Secure API wrapper for ML model"""

    def __init__(
        self,
        model: nn.Module,
        enable_rate_limiting: bool = True,
        enable_obfuscation: bool = True,
        enable_monitoring: bool = True
    ):
        self.model = model
        self.model.eval()

        self.query_monitor = QueryMonitor() if enable_monitoring else None
        self.obfuscator = PredictionObfuscator() if enable_obfuscation else None

    def predict(
        self,
        user_id: str,
        input_data: np.ndarray,
        return_probabilities: bool = False
    ) -> Dict:
        """Secure prediction endpoint"""

        # Monitor query
        if self.query_monitor:
            query_check = self.query_monitor.record_query(user_id, input_data)

            if not query_check["allowed"]:
                return {
                    "success": False,
                    "error": query_check["reason"],
                    "details": query_check
                }

        # Convert to tensor
        input_tensor = torch.FloatTensor(input_data).unsqueeze(0)

        # Get prediction
        with torch.no_grad():
            output = self.model(input_tensor)
            probabilities = torch.softmax(output, dim=1).numpy()[0]

        # Obfuscate if enabled
        if self.obfuscator:
            probabilities = self.obfuscator.obfuscate_prediction(
                probabilities,
                return_class_only=not return_probabilities
            )

        # Prepare response
        predicted_class = int(np.argmax(probabilities))

        response = {
            "success": True,
            "prediction": predicted_class
        }

        if return_probabilities:
            response["probabilities"] = probabilities.tolist()

        return response

class DataEncryptor:
    """Encrypt and decrypt ML data and models"""

    def __init__(self, password: str = None):
        if password:
            self.key = self._derive_key_from_password(password)
        else:
            self.key = Fernet.generate_key()

        self.cipher = Fernet(self.key)

    def _derive_key_from_password(self, password: str) -> bytes:
        """Derive encryption key from password"""

        salt = b'ml_security_salt_2024'  # In production, use random salt

        kdf = PBKDF2(
            algorithm=hashes.SHA256(),
            length=32,
            salt=salt,
            iterations=100000,
            backend=default_backend()
        )

        key = base64.urlsafe_b64encode(kdf.derive(password.encode()))
        return key

    def encrypt_numpy_array(self, data: np.ndarray) -> bytes:
        """Encrypt numpy array"""

        # Serialize array
        serialized = pickle.dumps(data)

        # Encrypt
        encrypted = self.cipher.encrypt(serialized)

        return encrypted

    def decrypt_numpy_array(self, encrypted_data: bytes) -> np.ndarray:
        """Decrypt numpy array"""

        # Decrypt
        decrypted = self.cipher.decrypt(encrypted_data)

        # Deserialize
        data = pickle.loads(decrypted)

        return data

    def encrypt_model_weights(self, model_state_dict: Dict) -> bytes:
        """Encrypt model weights"""

        # Convert tensors to numpy for serialization
        serializable_state = {}
        for key, value in model_state_dict.items():
            if hasattr(value, 'cpu'):
                serializable_state[key] = value.cpu().numpy()
            else:
                serializable_state[key] = value

        # Serialize and encrypt
        serialized = pickle.dumps(serializable_state)
        encrypted = self.cipher.encrypt(serialized)

        return encrypted

    def decrypt_model_weights(self, encrypted_weights: bytes) -> Dict:
        """Decrypt model weights"""

        # Decrypt and deserialize
        decrypted = self.cipher.decrypt(encrypted_weights)
        state_dict = pickle.loads(decrypted)

        return state_dict

    def save_encrypted_file(self, data: Any, filepath: str):
        """Save encrypted data to file"""

        serialized = pickle.dumps(data)
        encrypted = self.cipher.encrypt(serialized)

        with open(filepath, 'wb') as f:
            f.write(encrypted)

    def load_encrypted_file(self, filepath: str) -> Any:
        """Load encrypted data from file"""

        with open(filepath, 'rb') as f:
            encrypted = f.read()

        decrypted = self.cipher.decrypt(encrypted)
        data = pickle.loads(decrypted)

        return data

class SecureDataStore:
    """Secure storage for training data with access control"""

    def __init__(self, encryption_key: bytes = None):
        if encryption_key is None:
            encryption_key = Fernet.generate_key()

        self.encryptor = DataEncryptor()

        self,
        dataset_id: str,

    ) -> bool:

        # Check authorization
        if not self._check_authorization(user_id, "writer"):
            self._log_access(user_id, "store", dataset_id, success=False)
            return False

        # Encrypt data
        encrypted_data = self.encryptor.encrypt_numpy_array(data)

        # Store with metadata
        storage_record = {
            "dataset_id": dataset_id,
            "encrypted_data": encrypted_data,
            "metadata": metadata,
            "created_by": user_id,
            "checksum": self._calculate_checksum(data)
        }

        # In production, store to database or object storage
        filename = f"encrypted_{dataset_id}.bin"
        with open(filename, 'wb') as f:
            pickle.dump(storage_record, f)

        self._log_access(user_id, "store", dataset_id, success=True)

        return True

    def retrieve_dataset(
        self,
        dataset_id: str,
        user_id: str
    ) -> np.ndarray:
        """Retrieve and decrypt dataset"""

        # Check authorization
        if not self._check_authorization(user_id, "reader"):
            self._log_access(user_id, "retrieve", dataset_id, success=False)
            raise PermissionError(f"User {user_id} not authorized")

        # Load encrypted record
        filename = f"encrypted_{dataset_id}.bin"

        with open(filename, 'rb') as f:
            storage_record = pickle.load(f)

        # Decrypt data
        data = self.encryptor.decrypt_numpy_array(
            storage_record["encrypted_data"]
        )

        # Verify integrity
        checksum = self._calculate_checksum(data)
        if checksum != storage_record["checksum"]:
            raise ValueError("Data integrity check failed!")

        self._log_access(user_id, "retrieve", dataset_id, success=True)

        return data

    def _check_authorization(self, user_id: str, required_role: str) -> bool:
        """Check if user has required role"""

        for auth_user, role in self.authorized_users:
            if auth_user == user_id:
                if role == "admin":
                    return True
                if required_role == "reader" and role in ["reader", "writer", "admin"]:
                    return True
                if required_role == "writer" and role in ["writer", "admin"]:
                    return True

        return False

    def _calculate_checksum(self, data: np.ndarray) -> str:
        """Calculate checksum for integrity verification"""

        return hashlib.sha256(data.tobytes()).hexdigest()

            "action": action,
            "dataset_id": dataset_id,
            "success": success
        })

    def get_access_log(self) -> list:

    """Manage API keys and authentication"""

            api_key=api_key,
            role=role,
            rate_limit=rate_limit

        self.api_keys[api_key] = user_id

        return api_key

    def _generate_api_key(self, user_id: str) -> str:
        """Generate cryptographically secure API key"""

        random_bytes = secrets.token_bytes(32)
        timestamp = str(time.time()).encode()
        user_bytes = user_id.encode()

        combined = random_bytes + timestamp + user_bytes
        api_key = hashlib.sha256(combined).hexdigest()

        return f"sk_{api_key[:48]}"

    def verify_api_key(self, api_key: str) -> Optional[User]:
        """Verify API key and return user"""

        user_id = self.api_keys.get(api_key)
        if user_id:
            return self.users.get(user_id)
        return None

    def revoke_api_key(self, api_key: str) -> bool:
        """Revoke API key"""

        user_id = self.api_keys.pop(api_key, None)
        if user_id and user_id in self.users:
            self.users[user_id].api_key = None
            return True
        return False

class JWTManager:
    """Manage JWT tokens"""

    def __init__(self, secret_key: str, algorithm: str = "HS256"):
        self.secret_key = secret_key
        self.algorithm = algorithm

    def create_access_token(
        self,
        user_id: str,
        role: str,
        expires_delta: timedelta = None
    ) -> str:
        """Create JWT access token"""

        if expires_delta is None:
            expires_delta = timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)

        expire = datetime.utcnow() + expires_delta

        payload = {
            "user_id": user_id,
            "role": role,
            "exp": expire,
            "iat": datetime.utcnow()
        }

        token = jwt.encode(payload, self.secret_key, algorithm=self.algorithm)
        return token

    def verify_token(self, token: str) -> Dict:
        """Verify and decode JWT token"""

        try:
            payload = jwt.decode(
                token,
                self.secret_key,
                algorithms=[self.algorithm]
            )
            return payload
        except jwt.ExpiredSignatureError:
            raise HTTPException(status_code=401, detail="Token expired")
        except jwt.InvalidTokenError:
            raise HTTPException(status_code=401, detail="Invalid token")

class RateLimiter:
    """Rate limiting with sliding window"""

    def __init__(self):
        self.requests: Dict[str, List[float]] = defaultdict(list)

    def check_rate_limit(
        self,
        user_id: str,
        limit: int,
        window_seconds: int = 3600
    ) -> bool:
        """Check if user is within rate limit"""

        current_time = time.time()
        cutoff_time = current_time - window_seconds

        # Remove old requests
        self.requests[user_id] = [
            timestamp for timestamp in self.requests[user_id]
            if timestamp > cutoff_time
        ]

        # Check limit
        if len(self.requests[user_id]) >= limit:
            return False

        # Record new request
        self.requests[user_id].append(current_time)
        return True

    def get_remaining_quota(
        self,
        user_id: str,
        limit: int,
        window_seconds: int = 3600
    ) -> int:
        """Get remaining quota for user"""

        current_time = time.time()
        cutoff_time = current_time - window_seconds

        # Count recent requests
        recent_requests = sum(
            1 for timestamp in self.requests[user_id]
            if timestamp > cutoff_time
        )

        return max(0, limit - recent_requests)

    def has_budget(self) -> bool:
        """Check if privacy budget remains"""
        return self.spent_epsilon < self.epsilon

    def spend(self, amount: float):
        """Spend privacy budget"""
        self.spent_epsilon += amount

    def remaining(self) -> float:
        """Get remaining budget"""
        return max(0, self.epsilon - self.spent_epsilon)

class DifferentiallyPrivateOptimizer:
    """DP-SGD optimizer with gradient clipping and noise"""

    def __init__(
        self,
        optimizer: optim.Optimizer,
        l2_norm_clip: float = 1.0,
        noise_multiplier: float = 1.1,
        batch_size: int = 256,
        epsilon: float = 1.0,
        delta: float = 1e-5
    ):
        self.optimizer = optimizer
        self.l2_norm_clip = l2_norm_clip
        self.noise_multiplier = noise_multiplier
        self.batch_size = batch_size

        self.privacy_budget = PrivacyBudget(epsilon, delta)
        self.steps = 0

    def clip_gradients(self, parameters):
        """Clip gradients per-sample to bound sensitivity"""

        # Compute gradient norm
        total_norm = 0.0
        for p in parameters:
            if p.grad is not None:
                param_norm = p.grad.data.norm(2)
                total_norm += param_norm.item() ** 2

        total_norm = total_norm ** 0.5

        # Clip if necessary
        clip_coef = self.l2_norm_clip / (total_norm + 1e-6)
        if clip_coef < 1:
            for p in parameters:
                if p.grad is not None:
                    p.grad.data.mul_(clip_coef)

        return total_norm

    def add_noise(self, parameters):
        """Add Gaussian noise to gradients"""

        noise_scale = self.noise_multiplier * self.l2_norm_clip

        for p in parameters:
            if p.grad is not None:
                noise = torch.randn_like(p.grad) * noise_scale
                p.grad.data.add_(noise)

    def step(self, parameters):
        """Perform DP-SGD step"""

        # Clip gradients
        grad_norm = self.clip_gradients(parameters)

        # Add noise
        self.add_noise(parameters)

        # Update parameters
        self.optimizer.step()

        # Update privacy accounting
        self.steps += 1
        epsilon_spent = self._compute_epsilon_spent()
        self.privacy_budget.spent_epsilon = epsilon_spent

        return grad_norm

    def _compute_epsilon_spent(self) -> float:
        """Compute spent privacy budget using moments accountant"""

        # Simplified calculation (use opacus or tensorflow-privacy for accurate accounting)
        q = self.batch_size / 60000  # sampling probability (assuming MNIST-sized dataset)
        sigma = self.noise_multiplier

        # Strong composition theorem (simplified)
        epsilon = q * self.steps * (1 / (2 * sigma ** 2))

        return epsilon

    def get_privacy_spent(self) -> Tuple[float, float]:
        """Get spent privacy budget"""
        return (self.privacy_budget.spent_epsilon, self.privacy_budget.delta)

class PrivateAggregator:
    """Aggregate statistics with differential privacy"""

    def __init__(self, epsilon: float = 1.0):
        self.epsilon = epsilon

    def private_mean(
        self,
        data: np.ndarray,
        bounds: Tuple[float, float] = (0, 1)
    ) -> float:
        """Compute differentially private mean"""

        lower, upper = bounds
        sensitivity = (upper - lower) / len(data)

        # Clip data to bounds
        clipped_data = np.clip(data, lower, upper)

        # Compute mean
        true_mean = np.mean(clipped_data)

        # Add Laplace noise
        scale = sensitivity / self.epsilon
        noise = np.random.laplace(0, scale)

        private_mean = true_mean + noise

        return float(private_mean)

    def private_count(
        self,
        condition: np.ndarray
    ) -> int:
        """Count with differential privacy"""

        true_count = np.sum(condition)

        # Sensitivity is 1 for counting
        scale = 1.0 / self.epsilon
        noise = np.random.laplace(0, scale)

        private_count = true_count + noise

        # Round to integer
        return int(max(0, round(private_count)))

    def private_histogram(
        self,
        data: np.ndarray,
        bins: int = 10,
        range: Tuple[float, float] = None
    ) -> Tuple[np.ndarray, np.ndarray]:
        """Compute differentially private histogram"""

        # Compute true histogram
        counts, bin_edges = np.histogram(data, bins=bins, range=range)

        # Add Laplace noise to each bin
        # Sensitivity is 1 (one person can affect one bin)
        scale = 1.0 / self.epsilon

        private_counts = counts + np.random.laplace(0, scale, size=len(counts))
        private_counts = np.maximum(0, private_counts)  # No negative counts

        return private_counts, bin_edges

class FederatedLearningCoordinator:
    """Coordinate federated learning with privacy"""

    def __init__(
        self,
        model: nn.Module,
        num_clients: int,
        privacy_epsilon: float = 10.0
    ):
        self.global_model = model
        self.num_clients = num_clients
        self.privacy_epsilon = privacy_epsilon
        self.round = 0

    def aggregate_models(
        self,
        client_models: List[nn.Module],
        client_weights: List[int] = None
    ) -> nn.Module:
        """Aggregate client models using federated averaging"""

        if client_weights is None:
            client_weights = [1.0] * len(client_models)

        # Normalize weights
        total_weight = sum(client_weights)
        client_weights = [w / total_weight for w in client_weights]

        # Average model parameters
        global_dict = self.global_model.state_dict()

        for key in global_dict.keys():
            # Weighted average of client parameters
            global_dict[key] = sum(
                client_models[i].state_dict()[key] * client_weights[i]
                for i in range(len(client_models))
            )

            # Add noise for privacy
            if 'weight' in key or 'bias' in key:
                noise_scale = 0.01 * (self.num_clients / self.privacy_epsilon)
                noise = torch.randn_like(global_dict[key]) * noise_scale
                global_dict[key] += noise

        # Update global model
        self.global_model.load_state_dict(global_dict)
        self.round += 1

        return self.global_model

\section{Conclusion}

Security is paramount in production ML systems. This chapter covered the ML-specific threat landscape and defense mechanisms across multiple layers.

\textbf{Key Takeaways:}

\begin{enumerate}
    \item \textbf{ML Security is Unique:} Traditional security measures are necessary but insufficient. ML systems face adversarial attacks, model extraction, privacy leakage, and data poisoning that require specialized defenses.

    \item \textbf{Defense in Depth:} No single security measure is perfect. Layer multiple defenses: adversarial training, input validation, rate limiting, encryption, monitoring, and access controls.

    \item \textbf{Privacy Preservation:} Differential privacy and federated learning enable learning from sensitive data while providing mathematical privacy guarantees. The privacy-utility tradeoff must be carefully managed.

    \item \textbf{API Security Critical:} ML APIs are attack surfaces requiring authentication, authorization, rate limiting, input sanitization, and continuous monitoring.

    \item \textbf{Proactive Security:} Regular security scanning, vulnerability assessments, and penetration testing identify issues before attackers exploit them.

    \item \textbf{Security Overhead Acceptable:} The performance cost of security measures (10-30\% typical) is justified by risk reduction and regulatory compliance.
\end{enumerate}

\textbf{Security Checklist for ML Systems:}

\begin{itemize}
    \item[$\square$] Implement adversarial attack detection and defense
    \item[$\square$] Protect models from extraction with query monitoring and obfuscation
    \item[$\square$] Encrypt sensitive data at rest and in transit
    \item[$\square$] Secure model files with access controls and checksums
    \item[$\square$] Deploy authentication and authorization for all endpoints
    \item[$\square$] Implement rate limiting to prevent abuse
    \item[$\square$] Validate and sanitize all inputs
    \item[$\square$] Add differential privacy when handling sensitive data
    \item[$\square$] Monitor for security anomalies and failed access attempts
    \item[$\square$] Conduct regular security scans and penetration tests
    \item[$\square$] Maintain audit logs for all model access
    \item[$\square$] Keep dependencies updated and scan for vulnerabilities
    \item[$\square$] Train team on ML security best practices
    \item[$\square$] Establish incident response procedures
    \item[$\square$] Document security architecture and controls
\end{itemize}

\textbf{Future Directions:}

ML security is rapidly evolving. Emerging areas include:
\begin{itemize}
    \item \textbf{Certified Robustness:} Provable guarantees against adversarial attacks
    \item \textbf{Homomorphic Encryption:} Computation on encrypted data without decryption
    \item \textbf{Secure Multi-Party Computation:} Collaborative learning without data sharing
    \item \textbf{Zero-Knowledge Proofs:} Verify model properties without revealing internals
    \item \textbf{Quantum-Safe ML:} Protecting against quantum computing threats
    \item \textbf{AI-Powered Security:} Using ML to defend ML systems
\end{itemize}

Security must be built into ML systems from the design phase, not added as an afterthought. As ML systems increasingly make critical decisions affecting privacy, safety, and fairness, robust security becomes non-negotiable.

The techniques covered in this chapter provide a foundation for building secure ML systems. However, security is an ongoing process requiring continuous monitoring, updating, and improvement as new threats emerge and attack techniques evolve.

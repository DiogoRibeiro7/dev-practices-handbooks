\section{Introduction}

CI/CD for machine learning presents unique challenges beyond traditional software development. ML systems involve code, data, models, hyperparameters, and infrastructure that all need versioning, testing, and deployment automation. This chapter covers end-to-end CI/CD pipelines designed specifically for ML workflows.

\textbf{ML-Specific CI/CD Challenges:}

\begin{itemize}
    \item \textbf{Large Artifacts:} Models can be gigabytes in size, requiring special handling
    \item \textbf{Data Dependencies:} Tests need access to datasets, which may be large or sensitive
    \item \textbf{Compute Requirements:} Training requires GPUs, complicating CI infrastructure
    \item \textbf{Non-Determinism:} ML models may have slight variations between runs
    \item \textbf{Multiple Stakeholders:} Data scientists, ML engineers, and DevOps teams
    \item \textbf{Regulatory Compliance:} Model governance and audit trails
\end{itemize}

\textbf{Components of ML CI/CD:}

\begin{enumerate}
    \item \textbf{Code Testing:} Unit tests, integration tests for ML code
    \item \textbf{Data Validation:} Schema validation, data quality checks
    \item \textbf{Model Training:} Automated training on new data or code changes
    \item \textbf{Model Validation:} Performance testing, bias detection, safety checks
    \item \textbf{Model Deployment:} Automated deployment with canary releases
    \item \textbf{Monitoring Integration:} Connect deployed models to monitoring systems
    \item \textbf{Rollback Mechanisms:} Automatic rollback on performance degradation
\end{enumerate}

  EXPERIMENT_NAME: continuous-training

jobs:
  check-retraining-needed:
    runs-on: ubuntu-latest
    outputs:
      should_train: ${{ steps.check.outputs.should_train }}
      drift_detected: ${{ steps.drift.outputs.drift_detected }}

    steps:
    - name: Checkout code
      uses: actions/checkout@v3

    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.9'

    - name: Install dependencies
      run: |
        pip install mlflow pandas scikit-learn

    - name: Check data drift
      id: drift
      run: |
        python scripts/check_data_drift.py \
          --current-data data/processed/latest.csv \
          --reference-data data/processed/reference.csv \
          --threshold 0.1
        echo "drift_detected=$(cat drift_result.txt)" >> $GITHUB_OUTPUT

    - name: Check performance degradation
      id: performance
      run: |
        python scripts/check_model_performance.py \
          --model-id ${{ secrets.CURRENT_MODEL_ID }} \
          --test-data data/processed/test.csv \
          --threshold 0.02

    - name: Determine if retraining needed
      id: check
      run: |
        FORCE=${{ github.event.inputs.force_retrain }}
        DRIFT=${{ steps.drift.outputs.drift_detected }}

        if [ "$FORCE" = "true" ] || [ "$DRIFT" = "true" ]; then
          echo "should_train=true" >> $GITHUB_OUTPUT
        else
          echo "should_train=false" >> $GITHUB_OUTPUT
        fi

  train-and-deploy:
    needs: check-retraining-needed
    if: needs.check-retraining-needed.outputs.should_train == 'true'
    runs-on: [self-hosted, gpu]

    steps:
    - name: Checkout code

        python-version: '3.9'

        pip install -r requirements.txt
        pip install torch torchvision --index-url \
          https://download.pytorch.org/whl/cu118

    - name: Pull training data
      run: |
        dvc pull data/processed/train.csv.dvc

    - name: Train model with hyperparameter tuning
      run: |
        python src/train_with_tuning.py \
          --data-path data/processed/train.csv \

import pytest
import pandas as pd

class TestDataPreprocessing:
    """Test suite for data preprocessing"""

    def test_remove_outliers_iqr(self, sample_regression_data):
        """Test outlier removal using IQR method"""
        df = sample_regression_data.copy()
        original_len = len(df)

        # Add some outliers
        df.loc[0, 'feature_0'] = 1000
        df.loc[1, 'feature_1'] = -1000

        cleaned = remove_outliers(df, method='iqr', threshold=1.5)

        assert len(cleaned) < len(df)
        assert len(cleaned) >= original_len - 10  # Not too aggressive
        assert not cleaned.isnull().any().any()

    def test_encode_categorical_one_hot(self):
        """Test one-hot encoding of categorical variables"""
        df = pd.DataFrame({
            'color': ['red', 'blue', 'green', 'red'],
            'size': ['S', 'M', 'L', 'M'],
            'value': [1, 2, 3, 4]
        })

        encoded = encode_categorical(
            df,
            columns=['color', 'size'],
            method='onehot'
        )

        # Check new columns created
        assert 'color_red' in encoded.columns
        assert 'color_blue' in encoded.columns
        assert 'size_S' in encoded.columns

        # Check original columns removed
        assert 'color' not in encoded.columns
        assert 'size' not in encoded.columns

        # Check values preserved
        assert encoded['value'].tolist() == [1, 2, 3, 4]

    def test_scale_features_standard(self, sample_regression_data):
        """Test standard scaling of features"""
        df = sample_regression_data.copy()
        X = df.drop('target', axis=1)

        scaled, scaler = scale_features(X, method='standard')

        # Check mean close to 0 and std close to 1
        assert np.allclose(scaled.mean(axis=0), 0, atol=0.1)
        assert np.allclose(scaled.std(axis=0), 1, atol=0.1)

        # Check scaler can transform new data
        new_data = X.iloc[:10]
        transformed = scaler.transform(new_data)
        assert transformed.shape == new_data.shape

    def test_handle_missing_values_imputation(self):
        """Test missing value imputation"""
        df = pd.DataFrame({
            'a': [1, 2, np.nan, 4, 5],
            'b': [np.nan, 2, 3, 4, 5],
            'c': ['x', 'y', 'z', np.nan, 'w']
        })

        filled = handle_missing_values(
            df,
            strategy='mean',
            categorical_strategy='most_frequent'
        )

        assert not filled.isnull().any().any()
        assert filled['a'].iloc[2] == pytest.approx(3.0, rel=0.1)
        assert filled['c'].iloc[3] in ['x', 'y', 'z', 'w']

    def test_validate_data_schema(self, sample_classification_data):
        """Test data schema validation"""
        df = sample_classification_data

        schema = {

        # Missing column should fail

class DriftDetector:
    """Detect data drift and concept drift"""

    def __init__(self, reference_data: pd.DataFrame):
        self.reference_data = reference_data
        self.reference_stats = self._compute_statistics(reference_data)

    def _compute_statistics(self, data: pd.DataFrame) -> Dict:
        """Compute statistical properties of dataset"""
        stats = {}

        for col in data.select_dtypes(include=[np.number]).columns:
            stats[col] = {
                'mean': data[col].mean(),
                'std': data[col].std(),
                'min': data[col].min(),
                'max': data[col].max(),
                'q25': data[col].quantile(0.25),
                'q50': data[col].quantile(0.50),
                'q75': data[col].quantile(0.75)
            }

        return stats

    def detect_drift(self, current_data: pd.DataFrame) -> Dict[str, Any]:
        """Detect if data has drifted from reference"""
        current_stats = self._compute_statistics(current_data)

        drift_scores = {}
        for col in self.reference_stats:
            if col not in current_stats:
                continue

            # Calculate normalized difference in statistics
            ref = self.reference_stats[col]
            curr = current_stats[col]

            mean_diff = abs(curr['mean'] - ref['mean']) / (ref['std'] + 1e-6)
            std_ratio = curr['std'] / (ref['std'] + 1e-6)

            drift_scores[col] = {
                'mean_shift': mean_diff,
                'std_ratio': std_ratio,
                'drifted': mean_shift > 2.0 or abs(std_ratio - 1.0) > 0.5
            }

        # Overall drift assessment
        drifted_features = [
            col for col, score in drift_scores.items()
            if score['drifted']
        ]

        return {
            'drift_detected': len(drifted_features) > len(drift_scores) * 0.2,
            'drifted_features': drifted_features,
            'drift_scores': drift_scores,
            'num_drifted': len(drifted_features),
            'total_features': len(drift_scores)
        }

class PerformanceMonitor:
    """Monitor model performance in production"""

    def __init__(self, model_id: str, mlflow_tracking_uri: str):
        self.model_id = model_id
        mlflow.set_tracking_uri(mlflow_tracking_uri)
        self.logger = logging.getLogger(__name__)

    def check_performance_degradation(
        self,
        current_metrics: Dict[str, float],
        baseline_metrics: Dict[str, float],
        threshold: float = 0.02
    ) -> Dict[str, Any]:
        """Check if performance has degraded"""

        degradations = {}
        for metric, current_value in current_metrics.items():
            if metric not in baseline_metrics:
                continue

            baseline_value = baseline_metrics[metric]
            degradation = baseline_value - current_value

            degradations[metric] = {
                'current': current_value,
                'baseline': baseline_value,
                'degradation': degradation,
                'degraded': degradation > threshold
            }

        any_degraded = any(d['degraded'] for d in degradations.values())

        return {
            'performance_degraded': any_degraded,
            'metrics': degradations
        }

class ContinuousTrainingPipeline:
    """
    Automated continuous training pipeline

    Monitors data and performance, triggers retraining when needed
    """

    def __init__(
        self,
        config: TrainingConfig,
        mlflow_tracking_uri: str,
        data_source: str,
        model_registry_name: str
    ):
        self.config = config
        self.data_source = data_source
        self.model_registry_name = model_registry_name

        mlflow.set_tracking_uri(mlflow_tracking_uri)
        self.logger = logging.getLogger(__name__)

        self.drift_detector: Optional[DriftDetector] = None
        self.performance_monitor: Optional[PerformanceMonitor] = None

    def should_retrain(self) -> Dict[str, Any]:
        """Determine if model should be retrained"""

        reasons = []

        # Check 1: Data drift
        current_data = self._load_recent_data()

        if self.drift_detector is None:
            # Initialize drift detector with current data as reference
            self.drift_detector = DriftDetector(current_data)
            self.logger.info("Initialized drift detector with current data")

        drift_result = self.drift_detector.detect_drift(current_data)

        if drift_result['drift_detected']:
            reasons.append({
                'type': 'data_drift',
                'severity': 'high',
                'details': drift_result
            })
            self.logger.warning(
                f"Data drift detected in {drift_result['num_drifted']} features"
            )

        # Check 2: Performance degradation
        current_model = self._get_current_production_model()

        if current_model:
            current_metrics = self._evaluate_model(current_model, current_data)
            baseline_metrics = self._get_baseline_metrics()

            if self.performance_monitor is None:
                self.performance_monitor = PerformanceMonitor(
                    model_id=current_model['model_id'],
                    mlflow_tracking_uri=mlflow.get_tracking_uri()
                )

            perf_check = self.performance_monitor.check_performance_degradation(
                current_metrics,
                baseline_metrics,
                threshold=self.config.performance_threshold
            )

            if perf_check['performance_degraded']:
                reasons.append({
                    'type': 'performance_degradation',
                    'severity': 'high',
                    'details': perf_check
                })
                self.logger.warning("Performance degradation detected")

        # Check 3: Scheduled retraining
        last_training_time = self._get_last_training_time()
        time_since_training = datetime.now() - last_training_time

        if time_since_training > timedelta(days=7):  # Weekly retraining
            reasons.append({
                'type': 'scheduled',
                'severity': 'low',
                'details': {
                    'days_since_training': time_since_training.days
                }
            })

        # Check 4: Sufficient new data
        new_samples = len(current_data)
        if new_samples < self.config.min_training_samples:
            reasons.append({
                'type': 'insufficient_data',
                'severity': 'blocking',
                'details': {
                    'current_samples': new_samples,
                    'required_samples': self.config.min_training_samples
                }
            })

        # Decision
        should_train = any(
            r['severity'] in ['high', 'critical'] for r in reasons
        ) and not any(
            r['severity'] == 'blocking' for r in reasons
        )

        return {
            'should_retrain': should_train,
            'reasons': reasons,
            'timestamp': datetime.now().isoformat()
        }

    def train_and_validate(self) -> Dict[str, Any]:
        """Train new model and validate performance"""

        self.logger.info("Starting training pipeline...")

        # Start MLflow run
        with mlflow.start_run(run_name=f"continuous_training_{datetime.now().strftime('%Y%m%d_%H%M%S')}"):

            # Log configuration
            mlflow.log_params(self.config.hyperparameters)
            mlflow.set_tag("pipeline", "continuous_training")
            mlflow.set_tag("trigger", "automated")

            # Load and prepare data
            train_data, val_data = self._prepare_training_data()

            # Log data statistics
            mlflow.log_metric("train_samples", len(train_data))
            mlflow.log_metric("val_samples", len(val_data))

            # Train model
            model, training_metrics = self._train_model(train_data)

            # Log training metrics
            for metric_name, value in training_metrics.items():
                mlflow.log_metric(f"train_{metric_name}", value)

            # Validate model
            validation_metrics = self._validate_model(model, val_data)

            for metric_name, value in validation_metrics.items():
                mlflow.log_metric(f"val_{metric_name}", value)

            # Compare with baseline
            baseline_metrics = self._get_baseline_metrics()
            comparison = self._compare_with_baseline(
                validation_metrics,
                baseline_metrics
            )

            mlflow.log_dict(comparison, "baseline_comparison.json")

            # Log model
            mlflow.sklearn.log_model(
                model,
                "model",
                registered_model_name=self.model_registry_name
            )

            run_id = mlflow.active_run().info.run_id

            result = {
                'status': 'success',
                'run_id': run_id,
                'training_metrics': training_metrics,
                'validation_metrics': validation_metrics,
                'baseline_comparison': comparison,
                'model_improved': comparison['is_improvement']
            }

            self.logger.info(
                f"Training completed. Run ID: {run_id}, "
                f"Improved: {result['model_improved']}"
            )

            return result

    def deploy_if_improved(self, training_result: Dict[str, Any]) -> Dict[str, Any]:
        """Deploy new model if it's better than current"""

        if not training_result['model_improved']:
            self.logger.info("New model did not improve. Skipping deployment.")
            return {
                'deployed': False,
                'reason': 'no_improvement'
            }

        # Get model URI
        run_id = training_result['run_id']
        model_uri = f"runs:/{run_id}/model"

        model_version = mlflow.register_model(
            model_uri,
            self.model_registry_name
        )

            name=self.model_registry_name,
            version=model_version.version,
            stage="Staging"
        )

        self.logger.info(
            f"Model version {model_version.version} moved to Staging"
        )

        canary_result = self._run_canary_tests(model_version.version)

            client.transition_model_version_stage(
                name=self.model_registry_name,
                version=model_version.version,
                stage="Production"
            )

            # Archive old production model
            self._archive_old_production_model()

            self.logger.info(
                f"Model version {model_version.version} deployed to Production"
            )

            return {

"""Automated model validation with configurable gates"""

from typing import Dict, List, Any, Optional
from dataclasses import dataclass, field
from enum import Enum
import pandas as pd
import numpy as np
import logging

class ValidationStatus(Enum):
    """Status of validation check"""
    PASSED = "passed"
    FAILED = "failed"
    WARNING = "warning"
    SKIPPED = "skipped"

@dataclass
class ValidationResult:
    """Result of a single validation check"""
    check_name: str
    status: ValidationStatus
    message: str
    details: Dict[str, Any] = field(default_factory=dict)
    severity: str = "medium"  # low, medium, high, critical

@dataclass
class ModelValidationReport:
    """Complete validation report"""
    model_id: str
    timestamp: str
    overall_status: ValidationStatus
    checks: List[ValidationResult]
    blocking_issues: List[str] = field(default_factory=list)
    warnings: List[str] = field(default_factory=list)

class ModelValidator:
    """
    Comprehensive model validation system

    Performs multiple validation checks before model deployment
    """

    def __init__(self, validation_config: Dict[str, Any]):
        self.config = validation_config
        self.logger = logging.getLogger(__name__)

    def validate_model(
        self,
        model: Any,
        test_data: pd.DataFrame,
        metadata: Dict[str, Any]
    ) -> ModelValidationReport:
        """
        Run all validation checks on model

        Returns validation report with pass/fail status
        """

        self.logger.info(f"Starting validation for model {metadata.get('model_id')}")

        checks = []

        # Performance validation
        perf_result = self._validate_performance(model, test_data)
        checks.append(perf_result)

        # Fairness validation
        if 'sensitive_features' in self.config:
            fairness_result = self._validate_fairness(
                model,
                test_data,
                self.config['sensitive_features']
            )
            checks.append(fairness_result)

        # Robustness validation
        robustness_result = self._validate_robustness(model, test_data)
        checks.append(robustness_result)

        # Latency validation
        latency_result = self._validate_latency(model, test_data)
        checks.append(latency_result)

        # Explainability validation
        if self.config.get('require_explainability', False):
            explainability_result = self._validate_explainability(model)
            checks.append(explainability_result)

        # Schema validation
        schema_result = self._validate_input_schema(model, test_data)
        checks.append(schema_result)

        # Dependency validation
        dependency_result = self._validate_dependencies(metadata)
        checks.append(dependency_result)

        # Determine overall status
        blocking_issues = [
            c.check_name for c in checks
            if c.status == ValidationStatus.FAILED and c.severity in ['high', 'critical']
        ]

        warnings = [
            c.check_name for c in checks
            if c.status == ValidationStatus.WARNING or
            (c.status == ValidationStatus.FAILED and c.severity == 'medium')
        ]

        if blocking_issues:
            overall_status = ValidationStatus.FAILED
        elif any(c.status == ValidationStatus.FAILED for c in checks):
            overall_status = ValidationStatus.WARNING
        else:
            overall_status = ValidationStatus.PASSED

        report = ModelValidationReport(
            model_id=metadata.get('model_id', 'unknown'),
            timestamp=datetime.now().isoformat(),
            overall_status=overall_status,
            checks=checks,
            blocking_issues=blocking_issues,
            warnings=warnings
        )

        self.logger.info(f"Validation complete. Status: {overall_status.value}")

        return report

    def _validate_performance(
        self,
        model: Any,
        test_data: pd.DataFrame
    ) -> ValidationResult:
        """Validate model meets performance requirements"""

        X = test_data.drop('target', axis=1)
        y_true = test_data['target']

        y_pred = model.predict(X)

        from sklearn.metrics import accuracy_score, f1_score

        accuracy = accuracy_score(y_true, y_pred)
        f1 = f1_score(y_true, y_pred, average='weighted')

        # Check against thresholds
        min_accuracy = self.config.get('min_accuracy', 0.80)
        min_f1 = self.config.get('min_f1', 0.75)

        passed = accuracy >= min_accuracy and f1 >= min_f1

        return ValidationResult(
            check_name="performance",
            status=ValidationStatus.PASSED if passed else ValidationStatus.FAILED,
            message=(
                f"Accuracy: {accuracy:.3f} (>= {min_accuracy}), "
                f"F1: {f1:.3f} (>= {min_f1})"
            ),
            details={'accuracy': accuracy, 'f1_score': f1},
            severity='critical'
        )

    def _validate_fairness(
        self,
        model: Any,
        test_data: pd.DataFrame,
        sensitive_features: List[str]
    ) -> ValidationResult:
        """Validate model fairness across protected groups"""

        X = test_data.drop(['target'] + sensitive_features, axis=1)
        y_true = test_data['target']

        y_pred = model.predict(X)

        # Check demographic parity for each sensitive feature
        fairness_violations = []

        for feature in sensitive_features:
            groups = test_data[feature].unique()

            rates = {}
            for group in groups:
                mask = test_data[feature] == group
                rates[group] = y_pred[mask].mean()

            max_diff = max(rates.values()) - min(rates.values())

            threshold = self.config.get('fairness_threshold', 0.1)

            if max_diff > threshold:
                fairness_violations.append(
                    f"{feature}: max difference {max_diff:.3f}"
                )

        passed = len(fairness_violations) == 0

        return ValidationResult(
            check_name="fairness",
            status=ValidationStatus.PASSED if passed else ValidationStatus.WARNING,
            message=(
                "Fairness check passed" if passed
                else f"Fairness violations: {', '.join(fairness_violations)}"
            ),
            details={'violations': fairness_violations},
            severity='high'
        )

    def _validate_robustness(
        self,
        model: Any,
        test_data: pd.DataFrame
    ) -> ValidationResult:
        """Validate model robustness to perturbations"""

        X = test_data.drop('target', axis=1)
        y_true = test_data['target']

        baseline_pred = model.predict(X)

        # Add noise
        noise_std = X.std() * 0.1
        X_noisy = X + np.random.randn(*X.shape) * noise_std.values

        noisy_pred = model.predict(X_noisy)

        # Check prediction consistency
        consistency = (baseline_pred == noisy_pred).mean()

        threshold = self.config.get('robustness_threshold', 0.90)
        passed = consistency >= threshold

        return ValidationResult(
            check_name="robustness",
            status=ValidationStatus.PASSED if passed else ValidationStatus.WARNING,
            message=f"Prediction consistency: {consistency:.3f} (>= {threshold})",
            details={'consistency': consistency},
            severity='medium'
        )

    def _validate_latency(
        self,
        model: Any,
        test_data: pd.DataFrame
    ) -> ValidationResult:
        """Validate inference latency"""

        import time

        X = test_data.drop('target', axis=1).head(100)

        # Warmup
        _ = model.predict(X)

        # Measure
        times = []
        for _ in range(10):
            start = time.perf_counter()
            _ = model.predict(X)
            elapsed = (time.perf_counter() - start) * 1000
            times.append(elapsed)

        p95_latency = np.percentile(times, 95)

        max_latency = self.config.get('max_latency_ms', 100)
        passed = p95_latency < max_latency

        return ValidationResult(
            check_name="latency",
            status=ValidationStatus.PASSED if passed else ValidationStatus.FAILED,
            message=f"P95 latency: {p95_latency:.1f}ms (< {max_latency}ms)",
            details={'p95_latency_ms': p95_latency},
            severity='high'
        )

    def _validate_explainability(self, model: Any) -> ValidationResult:
        """Validate model explainability"""

        # Check if model supports explainability
        has_feature_importance = hasattr(model, 'feature_importances_')
        has_coef = hasattr(model, 'coef_')

        explainable = has_feature_importance or has_coef

        return ValidationResult(
            check_name="explainability",
            status=ValidationStatus.PASSED if explainable else ValidationStatus.WARNING,
            message="Model provides explainability" if explainable else "Model lacks explainability",
            details={'explainable': explainable},
            severity='low'
        )

    def _validate_input_schema(
        self,
        model: Any,
        test_data: pd.DataFrame
    ) -> ValidationResult:
        """Validate input schema matches expectations"""

        X = test_data.drop('target', axis=1)

        try:
            # Test prediction with expected schema
            _ = model.predict(X.head(1))

            return ValidationResult(
                check_name="schema",
                status=ValidationStatus.PASSED,
                message="Input schema validation passed",
                details={},
                severity='critical'
            )

        except Exception as e:
            return ValidationResult(
                check_name="schema",
                status=ValidationStatus.FAILED,
                message=f"Schema validation failed: {str(e)}",
                details={'error': str(e)},
                severity='critical'
            )

    def _validate_dependencies(self, metadata: Dict) -> ValidationResult:
        """Validate model dependencies are documented"""

        has_dependencies = 'dependencies' in metadata
        has_version = 'model_version' in metadata

        passed = has_dependencies and has_version

        return ValidationResult(
            check_name="dependencies",
            status=ValidationStatus.PASSED if passed else ValidationStatus.WARNING,
            message="Dependencies documented" if passed else "Missing dependency information",
            details=metadata.get('dependencies', {}),
            severity='low'
        )

"""Model registry client for CI/CD pipelines"""

from typing import Dict, List, Optional, Any
from dataclasses import dataclass
from datetime import datetime
import mlflow
from mlflow.tracking import MlflowClient
import logging

@dataclass
class ModelVersion:
    """Model version information"""
    name: str
    version: str
    stage: str
    creation_timestamp: datetime
    tags: Dict[str, str]
    description: Optional[str] = None

class MLModelRegistry:
    """
    Integration with MLflow Model Registry

    Manages model lifecycle from staging to production
    """

    def __init__(self, tracking_uri: str):
        mlflow.set_tracking_uri(tracking_uri)
        self.client = MlflowClient()
        self.logger = logging.getLogger(__name__)

    def register_model(
        self,
        run_id: str,
        model_name: str,
        tags: Optional[Dict[str, str]] = None,
        description: Optional[str] = None
    ) -> ModelVersion:
        """Register new model version"""

        model_uri = f"runs:/{run_id}/model"

        # Register model
        mv = mlflow.register_model(model_uri, model_name)

        # Add tags
        if tags:
            for key, value in tags.items():
                self.client.set_model_version_tag(
                    name=model_name,
                    version=mv.version,
                    key=key,
                    value=value
                )

        # Add description
        if description:
            self.client.update_model_version(
                name=model_name,
                version=mv.version,
                description=description
            )

        self.logger.info(
            f"Registered model {model_name} version {mv.version}"
        )

        return ModelVersion(
            name=model_name,
            version=mv.version,
            stage="None",
            creation_timestamp=datetime.fromtimestamp(mv.creation_timestamp / 1000),
            tags=tags or {},
            description=description
        )

    def promote_model(
        self,
        model_name: str,
        version: str,
        stage: str,
        archive_existing: bool = True
    ):
        """Promote model to new stage"""

        if archive_existing and stage == "Production":
            # Archive existing production models
            prod_models = self.client.get_latest_versions(
                model_name,
                stages=["Production"]
            )

            for model in prod_models:
                self.client.transition_model_version_stage(
                    name=model_name,
                    version=model.version,
                    stage="Archived"
                )
                self.logger.info(
                    f"Archived previous production version {model.version}"
                )

        # Promote new version
        self.client.transition_model_version_stage(
            name=model_name,
            version=version,
            stage=stage
        )

        self.logger.info(
            f"Promoted model {model_name} version {version} to {stage}"
        )

    def get_production_model(self, model_name: str) -> Optional[ModelVersion]:
        """Get current production model version"""

        prod_models = self.client.get_latest_versions(
            model_name,
            stages=["Production"]
        )

        if not prod_models:
            return None

        model = prod_models[0]

        return ModelVersion(
            name=model.name,
            version=model.version,
            stage=model.current_stage,
            creation_timestamp=datetime.fromtimestamp(model.creation_timestamp / 1000),
            tags=model.tags
        )

    def compare_models(
        self,
        model_name: str,
        version1: str,
        version2: str,
        metric_names: List[str]
    ) -> Dict[str, Any]:
        """Compare metrics between two model versions"""

        # Get runs for both versions
        mv1 = self.client.get_model_version(model_name, version1)
        mv2 = self.client.get_model_version(model_name, version2)

        run1 = self.client.get_run(mv1.run_id)
        run2 = self.client.get_run(mv2.run_id)

        comparison = {}

        for metric in metric_names:
            val1 = run1.data.metrics.get(metric)
            val2 = run2.data.metrics.get(metric)

            if val1 is not None and val2 is not None:
                comparison[metric] = {
                    f'version_{version1}': val1,
                    f'version_{version2}': val2,
                    'difference': val2 - val1,
                    'pct_change': ((val2 - val1) / val1) * 100 if val1 != 0 else 0
                }

        return comparison

      run: |
        python scripts/validate_model_cards.py \

    \item License compliance checking
    \item Model documentation and cards
    \item Audit trails for regulatory requirements
\end{itemize}

\textbf{8. Deployment Strategies:}
\begin{itemize}
    \item Blue-green for zero-downtime updates
    \item Canary for gradual rollout with monitoring
    \item A/B testing for model comparison
    \item Automatic rollback on failures
    \item Multi-environment progression
\end{itemize}

\textbf{Key Success Factors:}
\begin{enumerate}
    \item \textbf{Automation:} Automate everything from testing to deployment
    \item \textbf{Validation Gates:} Never deploy without passing all checks
    \item \textbf{Monitoring:} Watch models in production continuously
    \item \textbf{Rollback:} Always have a quick rollback strategy
    \item \textbf{Documentation:} Document models, decisions, and processes
    \item \textbf{Collaboration:} Design for data scientists and engineers
\end{enumerate}

CI/CD for ML requires adapting traditional software practices while adding ML-specific components. The investment in robust pipelines pays off through faster iteration, fewer production issues, and greater confidence in deployments.

\section{Introduction}

This appendix provides comprehensive installation and setup guides for all tools and frameworks mentioned throughout this book. Follow these guides to set up a complete ML engineering environment from scratch.

\textbf{Prerequisites:}
\begin{itemize}
    \item Basic command-line proficiency
    \item Administrator/root access to your system
    \item Internet connection for downloads
    \item Minimum 16GB RAM, 50GB free disk space
\end{itemize}

\section{Python Environment Setup}

\subsection{Installing Python 3.9+}

Python is the foundation of modern ML engineering. We recommend Python 3.9 or later.

\textbf{Windows:}
\begin{lstlisting}[style=shell]
# Method 1: Official installer
# Download from python.org and run installer
# Make sure to check "Add Python to PATH"

# Method 2: Using winget (Windows Package Manager)
winget install Python.Python.3.11

# Method 3: Using Chocolatey
choco install python --version=3.11.0

# Verify installation
python --version
pip --version
\end{lstlisting}

\textbf{macOS:}
\begin{lstlisting}[style=shell]
# Method 1: Using Homebrew (recommended)
brew install python@3.11

# Method 2: Using pyenv for version management
brew install pyenv
pyenv install 3.11.0
pyenv global 3.11.0

# Add to ~/.zshrc or ~/.bash_profile
echo 'export PATH="$HOME/.pyenv/shims:$PATH"' >> ~/.zshrc

# Verify installation
python3 --version
pip3 --version
\end{lstlisting}

\textbf{Linux (Ubuntu/Debian):}
\begin{lstlisting}[style=shell]
# Update package lists
sudo apt update

# Install Python 3.11
sudo apt install software-properties-common
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install python3.11 python3.11-venv python3.11-dev python3-pip

# Set as default (optional)
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.11 1

# Verify installation
python3 --version
pip3 --version
\end{lstlisting}

\textbf{Linux (CentOS/RHEL 8+):}
\begin{lstlisting}[style=shell]
# Enable EPEL repository
sudo dnf install epel-release

# Install Python 3.11
sudo dnf install python3.11 python3.11-devel

# Verify installation
python3.11 --version
pip3.11 --version
\end{lstlisting}

\section{Docker Installation and Configuration}

Docker containers provide consistent environments across different systems.

\subsection{Docker Desktop (Windows/macOS)}

\textbf{Installation:}
\begin{enumerate}
    \item Download Docker Desktop from \url{https://www.docker.com/products/docker-desktop}
    \item Run the installer
    \item Start Docker Desktop from Applications
    \item Configure resources: Settings → Resources → Advanced
    \begin{itemize}
        \item CPUs: 4+
        \item Memory: 8GB+
        \item Disk: 100GB+
    \end{itemize}
    \item Enable Kubernetes (optional): Settings → Kubernetes → Enable
\end{enumerate}

\textbf{Verification:}
\begin{lstlisting}[style=shell]
# Check Docker version
docker --version
docker-compose --version

# Test Docker installation
docker run hello-world

# Check running containers
docker ps

# Check Docker system info
docker system info
\end{lstlisting}

\subsection{Docker Engine (Linux)}

\textbf{Ubuntu/Debian:}
\begin{lstlisting}[style=shell]
# Remove old versions
sudo apt remove docker docker-engine docker.io containerd runc

# Install prerequisites
sudo apt update
sudo apt install ca-certificates curl gnupg lsb-release

# Add Docker's official GPG key
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
    sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# Set up repository
echo \
  "deb [arch=$(dpkg --print-architecture) \
  signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Install Docker Engine
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io \
    docker-buildx-plugin docker-compose-plugin

# Add user to docker group (avoid sudo)
sudo usermod -aG docker $USER
newgrp docker

# Enable Docker service
sudo systemctl enable docker
sudo systemctl start docker

# Verify installation
docker run hello-world
\end{lstlisting}

\textbf{CentOS/RHEL:}
\begin{lstlisting}[style=shell]
# Remove old versions
sudo yum remove docker docker-client docker-client-latest \
    docker-common docker-latest docker-latest-logrotate \
    docker-logrotate docker-engine

# Install yum-utils
sudo yum install -y yum-utils

# Add Docker repository
sudo yum-config-manager --add-repo \
    https://download.docker.com/linux/centos/docker-ce.repo

# Install Docker Engine
sudo yum install docker-ce docker-ce-cli containerd.io \
    docker-buildx-plugin docker-compose-plugin

# Start Docker
sudo systemctl start docker
sudo systemctl enable docker

# Add user to docker group
sudo usermod -aG docker $USER

# Verify
docker run hello-world
\end{lstlisting}

choco install kubernetes-cli

\textbf{Starting Minikube:}

\begin{lstlisting}[style=shell]

minikube addons enable ingress

minikube status

# Access dashboard
minikube dashboard

# Stop minikube
minikube stop

# Delete cluster
minikube delete
\end{lstlisting}

\subsection{Kind (Kubernetes in Docker)}

Kind is another option for local Kubernetes development.

\begin{lstlisting}[style=shell]
# Install kind
# macOS/Linux
curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.20.0/kind-linux-amd64
chmod +x ./kind
sudo mv ./kind /usr/local/bin/kind

# Create cluster
kind create cluster --name ml-cluster

# Create multi-node cluster
cat <<EOF | kind create cluster --config=-
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
- role: control-plane
- role: worker
- role: worker
EOF

# List clusters
kind get clusters

# Delete cluster
kind delete cluster --name ml-cluster
\end{lstlisting}

\section{Complete Environment Setup Script}

This script sets up a complete ML engineering environment:

\begin{lstlisting}[style=shell, caption=setup\_ml\_environment.sh]
#!/bin/bash
set -e

echo "Setting up ML Engineering Environment..."

# Variables
PROJECT_NAME=${1:-ml_project}
PYTHON_VERSION=${2:-3.11}

echo "Project name: $PROJECT_NAME"
echo "Python version: $PYTHON_VERSION"

# Create project directory
mkdir -p $PROJECT_NAME
cd $PROJECT_NAME

echo "Creating virtual environment..."
python${PYTHON_VERSION} -m venv venv
source venv/bin/activate

# Upgrade pip
echo "Upgrading pip..."
pip install --upgrade pip setuptools wheel

# Install ML frameworks
echo "Installing ML frameworks..."
pip install torch torchvision torchaudio
pip install tensorflow
pip install scikit-learn xgboost lightgbm

# Install data science stack
echo "Installing data science libraries..."
pip install numpy pandas scipy matplotlib seaborn plotly

# Install Jupyter
echo "Installing Jupyter..."
pip install jupyter jupyterlab ipywidgets

# Install MLOps tools
echo "Installing MLOps tools..."
pip install mlflow dvc wandb

# Install serving frameworks
echo "Installing serving frameworks..."
pip install fastapi uvicorn pydantic

# Install testing tools
echo "Installing testing tools..."
pip install pytest pytest-cov pytest-mock

# Install code quality tools
echo "Installing code quality tools..."
pip install black flake8 mypy pylint isort

# Install additional tools
echo "Installing additional tools..."
pip install python-dotenv pyyaml requests boto3

# Initialize git
echo "Initializing git repository..."
git init
curl -sL https://raw.githubusercontent.com/github/gitignore/main/Python.gitignore \
    -o .gitignore

# Initialize DVC
echo "Initializing DVC..."
dvc init

# Create project structure
echo "Creating project structure..."
mkdir -p data/{raw,processed,features,external}
mkdir -p models/{trained,registry}
mkdir -p notebooks/{exploratory,reporting}
mkdir -p src/{data,features,models,utils,api}
mkdir -p tests/{unit,integration}
mkdir -p config
mkdir -p logs
mkdir -p docs
mkdir -p scripts

# Create __init__.py files
touch src/__init__.py
touch src/data/__init__.py
touch src/features/__init__.py
touch src/models/__init__.py
touch src/utils/__init__.py
touch src/api/__init__.py
touch tests/__init__.py
touch tests/unit/__init__.py
touch tests/integration/__init__.py

# Create requirements.txt
echo "Creating requirements.txt..."
pip freeze > requirements.txt

# Create .env template
echo "Creating .env template..."
cat > .env.template << 'EOF'
# Environment variables template
MLFLOW_TRACKING_URI=http://localhost:5000
AWS_PROFILE=default
WANDB_API_KEY=your_key_here
PYTHONPATH=./src
EOF

# Create README
echo "Creating README.md..."
cat > README.md << EOF
# $PROJECT_NAME

ML Engineering Project

## Setup

\`\`\`bash
# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows

# Install dependencies
pip install -r requirements.txt

# Copy environment variables
cp .env.template .env
# Edit .env with your values
\`\`\`

## Project Structure

\`\`\`

\section{Troubleshooting Common Issues}

\subsection{Python Installation Issues}

\textbf{Issue: pip not found after Python installation}
\begin{lstlisting}[style=shell]
# Solution: Reinstall pip
python -m ensurepip --upgrade

# Or download get-pip.py
curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py
python get-pip.py
\end{lstlisting}

\textbf{Issue: Permission denied when installing packages}
\begin{lstlisting}[style=shell]
# Solution: Use --user flag
pip install --user package_name

# Or use virtual environment (recommended)
python -m venv venv
source venv/bin/activate
pip install package_name
\end{lstlisting}

\subsection{Docker Issues}

\textbf{Issue: Cannot connect to Docker daemon}
\begin{lstlisting}[style=shell]
# Solution 1: Start Docker service
sudo systemctl start docker

# Solution 2: Add user to docker group
sudo usermod -aG docker $USER
newgrp docker

# Solution 3: Check Docker socket permissions
sudo chmod 666 /var/run/docker.sock
\end{lstlisting}

\section{Verification Checklist}

After completing the setup, verify your environment:

\begin{enumerate}
    \item \textbf{Python}: \texttt{python --version} shows Python 3.9+
    \item \textbf{pip}: \texttt{pip --version} works
    \item \textbf{Virtual environment}: Can create and activate venv
    \item \textbf{Docker}: \texttt{docker run hello-world} succeeds
    \item \textbf{PyTorch}: Can import and detect GPU if available
    \item \textbf{TensorFlow}: Can import and list devices
    \item \textbf{MLflow}: \texttt{mlflow --version} works
    \item \textbf{DVC}: \texttt{dvc version} works
    \item \textbf{Jupyter}: Can start and access Jupyter Lab
    \item \textbf{Git}: \texttt{git --version} works
\end{enumerate}

Run this verification script:

\begin{lstlisting}[style=python, caption=verify\_setup.py]
#!/usr/bin/env python
"""Verify ML environment setup"""

import sys

def check_import(module_name, package_name=None):
    """Check if module can be imported"""
    try:
        __import__(module_name)
        print(f"✓ {package_name or module_name}")
        return True
    except ImportError:
        print(f"✗ {package_name or module_name} - Not installed")
        return False

def check_gpu():
    """Check GPU availability"""
    try:
        import torch
        if torch.cuda.is_available():
            print(f"✓ GPU available: {torch.cuda.get_device_name(0)}")
            return True
        else:
            print("✗ GPU not available (CPU only)")
            return False
    except:
        return False

print("Python Environment Verification")
print("=" * 50)
print(f"Python version: {sys.version}")
print()

modules = [
    ("torch", "PyTorch"),
    ("tensorflow", "TensorFlow"),
    ("sklearn", "scikit-learn"),
    ("numpy", "NumPy"),
    ("pandas", "pandas"),
    ("matplotlib", "Matplotlib"),
    ("mlflow", "MLflow"),
    ("fastapi", "FastAPI"),
    ("jupyter", "Jupyter"),
]

print("Checking installed packages:")
all_ok = all(check_import(mod, name) for mod, name in modules)

print("\nChecking GPU:")
check_gpu()

print("\n" + "=" * 50)
if all_ok:
    print("✓ All required packages installed!")
else:
    print("✗ Some packages missing. Run: pip install -r requirements.txt")
\end{lstlisting}

Run with: \texttt{python verify\_setup.py}

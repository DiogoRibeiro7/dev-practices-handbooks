\section{From Project Plans to Continuous Delivery}
Slide plans describe intent; Jira describes execution. Move from static project plans to continuous delivery by turning roadmaps into a living backlog, linking work to releases, and reviewing progress through actual flow data instead of status decks.

\subsection{How Jira replaces slide plans}
A slide plan shows a timeline; Jira shows a network of commitments. Replace milestone slides with release versions and Epic progress. Replace weekly status decks with dashboards that show cycle time, progress to release, and risk flags. The result is less narrative and more evidence.

\subsection{Worked scenario: quarterly plan update}
A quarterly plan is due. Instead of a deck, the PM uses Jira releases and Epic progress to show what will ship. The TPM highlights blocked dependencies. The EM shows throughput and WIP to justify capacity. The review focuses on trade-offs rather than optimistic dates.

\subsection{Case study insert}
The quarterly plan for PulseBoard is expressed as Release R1 with EPIC-1, EPIC-4, and EPIC-5. Status slides are replaced by Jira release progress and the dependency list for TS-104 and TS-117.
\subsection{Checklist}
\begin{itemize}
  \item Roadmap items are represented as Epics linked to releases.
  \item Release versions replace slide milestones.
  \item Dashboards replace status slides for weekly reporting.
  \item Capacity is grounded in throughput and WIP, not optimism.
  \item Risk and dependency fields are updated before review meetings.
\end{itemize}

\subsection{Failure modes and fixes}
\begin{enumerate}
  \item \textbf{Failure:} Teams maintain both slides and Jira. \textbf{Fix:} Make Jira the source and export views for execs.
  \item \textbf{Failure:} Releases are defined but never updated. \textbf{Fix:} Tie release updates to sprint review cadence.
  \item \textbf{Failure:} Progress is reported as percent complete. \textbf{Fix:} Report based on done scope and flow metrics.
  \item \textbf{Failure:} Risk is discussed but not recorded. \textbf{Fix:} Require Risk field updates for every Epic review.
  \item \textbf{Failure:} Stakeholders demand fixed dates without evidence. \textbf{Fix:} Use throughput data and dependency links to reset expectations.
\end{enumerate}

\chapter{Message Catalogue for Data Pipelines}

\section{Checklist: Catalogue Use}
\begin{itemize}
\item Event name is consistent across jobs.
\item Fields match the table entries.
\item IDs are present for traceability.
\item Outcome matches the level.
\end{itemize}

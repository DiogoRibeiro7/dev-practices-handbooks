\chapter{Quick Reference}
This appendix summarizes essential practices for fast recall.

\section{Do}
\begin{itemize}
\item Write messages that describe event name and outcome.
\item Use consistent levels across services.
\item Include correlation IDs with every request log.
\item Keep field names stable and documented.
\end{itemize}

\section{Avoid}
\begin{itemize}
\item Logging secrets or personal data.
\item Duplicating the same error at multiple layers.
\item Vague messages like \texttt{"failed"} without fields.
\item High-volume debug logs in production.
\end{itemize}

\section{Quick Checklist}
\begin{itemize}
\item Event name present.
\item Outcome explicit.
\item Level matches outcome.
\item IDs and fields included.
\end{itemize}

\chapter{Deployments}

Deployments should be repeatable and low risk.
If a deploy requires heroics, the system is too fragile.

\section{Deployment strategy}
Choose a strategy that fits your traffic and risk profile.
Blue-green and canary deploys reduce blast radius.

\section{Migrations}
Run migrations separately from application rollouts.
Use backward-compatible schema changes.

\section{Rollback}
Rollbacks should be safe and fast.
Keep previous versions ready to redeploy.

\section{Configuration}
Keep configuration external to the code.
Use environment variables or a config service.

\begin{checklistbox}{Checklist: deployments}
\begin{itemize}[nosep]
  \item Automate deploys.
  \item Separate migrations from rollouts.
  \item Practice rollbacks.
\end{itemize}
\end{checklistbox}

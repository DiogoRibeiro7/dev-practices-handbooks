\chapter{Multi-tenancy}

Multi-tenancy is a product choice and a risk model.

\section{Isolation models}
\begin{itemize}[nosep]
  \item shared database, shared schema, tenant id column
  \item shared database, schema per tenant
  \item database per tenant
\end{itemize}

\section{Security and correctness}
Tenant isolation must be enforced in the data access layer.
Avoid relying on application code scattered across endpoints.

\begin{patternbox}{Pattern: tenant scoping in queries}
Inject tenant scope as part of query building.
Make it hard to run an unscoped query by accident.
\end{patternbox}

\section{Operational considerations}
Multi-tenant systems need:
\begin{itemize}[nosep]
  \item per-tenant rate limits
  \item per-tenant quotas
  \item noisy neighbour controls
\end{itemize}

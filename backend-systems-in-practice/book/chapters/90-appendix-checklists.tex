\chapter{Checklists}

This appendix is meant to be used.
Copy sections into your repository docs.

\section{API checklist}
\begin{itemize}[nosep]
  \item consistent pagination
  \item stable error format
  \item idempotency for retryable operations
  \item clear authn/authz rules
  \item rate limiting strategy
\end{itemize}

\section{Database checklist}
\begin{itemize}[nosep]
  \item constraints for invariants
  \item indexes aligned with queries
  \item migrations measured and reversible where possible
  \item connection pooling monitored
\end{itemize}

\section{Operations checklist}
\begin{itemize}[nosep]
  \item structured logs with request ids
  \item latency and error dashboards
  \item alerts tied to SLOs
  \item runbooks and on-call ownership
\end{itemize}

\section{Security checklist}
\begin{itemize}[nosep]
  \item secrets not in code or logs
  \item least privilege access controls
  \item dependency scanning
  \item input validation at the boundary
\end{itemize}

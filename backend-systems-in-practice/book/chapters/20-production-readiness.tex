\chapter{Production readiness}

Production readiness is a discipline.
A backend is ready when it can be deployed, observed, and operated safely.

\section{Runbooks}
Write runbooks for common incidents.
Keep them short and specific.

\section{Alerts}
Alerts should be actionable.
Page on symptoms, not on every metric.

\section{Capacity}
Know your limits before you hit them.
Track usage and plan for growth.

\section{On-call}
On-call is part of the product.
Improve the system when you are paged, not just the alert.

\begin{checklistbox}{Checklist: production readiness}
\begin{itemize}[nosep]
  \item Have runbooks for critical incidents.
  \item Alert on user-visible symptoms.
  \item Review capacity regularly.
\end{itemize}
\end{checklistbox}

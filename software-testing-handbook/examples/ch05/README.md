# Chapter 5 Governance Examples

These scripts capture a deterministic quality review narrative for Chapter 5 governance rituals.

## Requirements

- Python 3.11+
- Install `pytest`.

## Run locally

```bash
cd software-testing-handbook
python examples/ch05/quality_review.py
```

## Run tests (CI-friendly)

```bash
cd software-testing-handbook
pytest examples/ch05
```

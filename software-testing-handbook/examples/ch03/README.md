# Chapter 3 Examples

CI automation scripts for Chapter 3, showing pipeline planning and deterministic gate ordering.

## Requirements

- Python 3.11+
- Install `pytest` (`pip install pytest`)

## Run locally

```bash
cd software-testing-handbook
python examples/ch03/ci_pipeline.py
```

## Run tests (CI-friendly)

```bash
cd software-testing-handbook
pytest examples/ch03
```

# Chapter 4 Examples

Metrics automation scripts demonstrating KPI narratives, SLI/SLO burn, and alert threshold logic.

## Requirements

- Python 3.11+
- Install pytest: `pip install pytest`

## Run locally

```bash
cd software-testing-handbook
python examples/ch04/metrics_kpi.py
```

## Run tests

```bash
cd software-testing-handbook
pytest examples/ch04
```

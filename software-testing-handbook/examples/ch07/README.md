# Chapter 7 Doubling Tests Examples

This example demonstrates choosing, injecting, and spying on doubles for notification workflows so CI suites remain deterministic and observable.

## Requirements

- Python 3.11+
- Install `pytest`.

## Run locally

```bash
cd software-testing-handbook
python examples/ch07/double_strategies.py
```

## Run tests

```bash
cd software-testing-handbook
pytest examples/ch07
```

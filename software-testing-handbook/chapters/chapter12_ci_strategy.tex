\section{Opening: Motivation and Learning Objectives}
Describe how a well-tuned CI pipeline keeps tests fast and actionable. Readers will understand parallelism, caching, selective execution, and reporting strategies.

\section{Core Concepts}
\begin{itemize}
  \item Designing pipelines for fast feedback using parallel jobs and sharding.
  \item Caching dependencies and artifacts to avoid cold starts.
  \item Selective testing (changed-files heuristics, smoke-first suites, tagging critical paths).
  \item Reporting results: dashboards, annotations, and alerts.
\end{itemize}

\section{Anti-patterns and Common Mistakes}
\begin{itemize}
  \item Running the entire suite sequentially on every push instead of narrowing the scope slows feedback to a crawl.
  \item Ignoring cache invalidation leads to stale dependencies and nondeterministic builds.
  \item Hiding failure context (logs, artifacts) leaves reviewers guessing why jobs failed, which encourages reruns instead of fixes.
\end{itemize}

\section{Worked Example}
\begin{lstlisting}[language=bash]
name: Test Matrix
on: [push, pull_request]
jobs:
  smoke:
    runs-on: ubuntu-latest
    strategy: { matrix: { python: [3.10, 3.11] } }
    steps:
      - checkout
      - restore-cache: pip-${{ matrix.python }}
      - run: pytest smoke --maxfail=1
      - save-cache: pip-${{ matrix.python }}
  regression:
    runs-on: ubuntu-latest
    needs: smoke
    steps:
      - checkout
      - restore-cache: pip-stable
      - run: pytest regression
      - save-artifact: regression-report
\end{lstlisting}

The matrix runs smoke suites in parallel while the regression job reuses cached deps, uploads artifacts, and depends on successful smoke results.

\section{Checklist}
\begin{itemize}
  \item Verify caches hit by checking cache restore steps and failing fast if a cache miss leaves tests offline.
  \item Publish artifacts (logs, coverage) after each stage for later triage.
  \item Capture failure fingerprints (e.g., failing test names, container IDs) alongside each failed job for faster debugging.
\end{itemize}

\section{Exercises}
\begin{enumerate}
  \item Split your suite into fast (lint/unit) and slow (integration/regression) groups and measure their durations.
  \item Measure cache hit rates for dependencies and log misses per run.
  \item Build change-aware filters that run critical smoke suites when backend files change.
  \item Create a CI watchdog that reports when pipelines exceed their time budget.
  \item Design alerts that surface failure context (logs, artifacts) immediately to Slack or Teams.
  \item Simulate a cache miss across jobs and document how you would recover deterministically.
\end{enumerate}
